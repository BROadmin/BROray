BROray 2.1.0

Поддерживаемая среда:
- KeeneticOS
- Entware
- Linux aarch64
- BusyBox 1.37.0 / ash

Прямые зависимости Entware:
- ca-bundle
- ca-certificates
- curl
- jq
- lighttpd
- lighttpd-mod-cgi
- wget-ssl (для первичного подключения HTTPS-репозитория)

Зависимости, устанавливаемые OPKG автоматически:
- libc
- libcurl
- libgcc
- libgmp
- libnettle
- libnghttp2
- libopenssl
- libpcre2
- libpthread
- librt
- libssp
- libstdcpp
- zlib

Встроенные компоненты:
- Xray 26.7.11 linux/arm64 из официального релиза XTLS/Xray-core
- авторизованный BROray WebUI
- BROray Connection Monitor
- BROray Server Auto Switch
- BROray Subscription Scheduler

Команды KeeneticOS, необходимые установщику:
- ndmc
- ip http proxy
