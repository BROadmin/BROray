# BROray WebUI — Stage 6

Build ID: `20260725-webui-final-clean-06`

Все страницы нового WebUI перенесены в единый `allpage.css`:

- Главная;
- Серверы;
- Подписки;
- Маршруты;
- Keenetic;
- Xray;
- BROray;
- страница входа.

Страница BROray использует канонические карточки, строки компонентов, статусы и общий фирменный диалог с обязательной контрольной фразой для удаления. Толстая разделительная линия в техническом блоке удалена.

Legacy-CSS и неиспользуемые JavaScript-файлы удалены из параллельной сборки. Рабочий `/opt/broray/web-new` этим этапом не переключается.
