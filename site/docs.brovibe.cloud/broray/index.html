BROray

Менеджер Xray для Keenetic и Netcraze с WebUI, подписками, выбором серверов и управляемыми маршрутами.

BROray 2.1.1 OPKG 2.1.1-2 aarch64 / arm64 BusyBox / ash
Проверено на реальных устройствах Обновление успешно проверено на Keenetic Peak KN-2710 EAEU и Keenetic Hopper KN-3811 EAEU. Обновление и чистая установка успешно проверены на Keenetic Ultra KN-1811 EAEU. Чистая установка успешно проверена на Keenetic Peak KN-2710 EAEU и Netcraze Ultra NC-1812 EAEU.
Keenetic и Netcraze С 2025 года часть устройств для рынка ЕАЭС выпускается под брендом Netcraze. В списке проверенных устройств такие модели указываются отдельно по фактическому бренду и индексу модели.

Исходный код: GitHub BROadmin/BROray.

Обсуждение и поддержка: Telegram-канал BROvibe.

1. Требования

  • Keenetic или Netcraze с архитектурой aarch64/arm64;
  • установленный Entware;
  • доступ к терминалу Entware под root;
  • доступ роутера в интернет;
  • достаточно свободного места в /opt.

2. Установка BROray

Для чистой установки выполните один блок целиком:

opkg update &&
opkg install ca-bundle ca-certificates wget-ssl &&
TARGET="/tmp/broray-install-2.1.1-2.sh" &&
/opt/bin/wget -qO "$TARGET.part" \
    "https://api.brovibe.cloud/releases/broray-install-2.1.1-2.sh?v=$(date +%s)" &&
echo "f14a86fc481d1a5c5c294635fe79031f71aa999d432b48be00c3a137ab7b8396  $TARGET.part" | sha256sum -c - &&
mv "$TARGET.part" "$TARGET" &&
/opt/bin/ash "$TARGET"

3. Открытие WebUI

Стандартный локальный адрес: http://192.168.1.1:8080/. Фактический LAN-адрес определяется автоматически.

4. Добавление подписки

  1. Откройте страницу «Подписки».
  2. Укажите название и вставьте полную ссылку подписки.
  3. Добавьте подписку и импортируйте нужные серверы.

5. Выбор сервера

  1. Откройте страницу «Серверы».
  2. Проверьте нужную конфигурацию и активируйте сервер.
  3. Дождитесь проверки Xray и отметки активного сервера.

6. Интерфейс Keenetic

BROray создаёт и обслуживает штатный прокси-интерфейс KeeneticOS/NDMS. Состояние, адрес Xray, связь и подключение отображаются на странице «Keenetic».

7. Маршруты

Встроены девять независимых наборов: Telegram, WhatsApp, YouTube, ChatGPT, Facebook, Instagram, Meta, TikTok и Speedtest.

BROray умеет находить все BAT-файлы источника, определять добавленные, изменённые и удалённые файлы, скачивать новую версию, устанавливать, обновлять и восстанавливать маршруты. Общие маршруты других наборов сохраняются.

Также поддерживается безопасная загрузка собственных BAT-файлов без выполнения содержащихся в них команд.

8. Обновление BROray

Обновление работает для любой установленной версии BROray. Выполните один блок целиком:

opkg update &&
opkg install ca-bundle ca-certificates wget-ssl &&
TARGET="/tmp/broray-safe-upgrade-2.1.1-2.sh" &&
/opt/bin/wget -qO "$TARGET.part" \
    "https://api.brovibe.cloud/releases/broray-safe-upgrade-2.1.1-2.sh?v=$(date +%s)" &&
echo "1cfcc536215825a29f087582483297baaecabb68fe641dd4ddc960f7146e9504  $TARGET.part" | sha256sum -c - &&
mv "$TARGET.part" "$TARGET" &&
/opt/bin/ash "$TARGET"

Обновитель очищает старые резервные копии, временные файлы, журналы и OPKG-кэш до резервного копирования. Проверенная резервная копия создаётся в /tmp. При ошибке выполняется автоматический откат.

10. Удаление

opkg remove broray
