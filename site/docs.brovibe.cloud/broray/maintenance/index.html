BROray · 3.5.7 · Stable

Обслуживание BROray

Обновление 3.5, копии настроек, восстановление и удаление. Xray и приложение обслуживаются отдельно.

Для установленной 3.2Эти инструкции по обновлению относятся к 3.5. Для перехода с 3.2 требуется чистая установка по пошаговому руководству. Не запускайте обновитель 3.2 для установки 3.5.

Обновить BROray 3.5

  1. Сохраните резервную копию настроек.
  2. Откройте «BROray → Проверить обновление».
  3. Прочитайте сведения о доступной версии и запустите установку.
  4. Дождитесь завершения операции. Во время смены приложения WebUI может временно отключиться.
  5. Снова откройте WebUI и войдите. Проверьте версию, Xray и активное подключение.

Если версия уже актуальна, обновление не требуется. Переустановка текущего выпуска — отдельное действие; кнопка доступна, когда канал предоставляет подходящий подписанный архив. Обновление BROray не заменяет выбранный Xray и не требует перезагрузки роутера.

Обновить Xray или маршруты отдельно

Для Xray откройте его страницу, проверьте версии и совместимость и выберите нужную. Для готовых маршрутов используйте проверку обновлений каталога и установку нужного набора. Это не требует выпуска новой версии BROray. Перевод на другое ядро или набор не меняет номер приложения.

Xray: обновление, нехватка места и удаление

  1. Откройте страницу Xray и нажмите Проверить версии.
  2. Выберите версию и прочитайте сведения о совместимости.
  3. Оставьте режим по умолчанию и нажмите Установить выбранную версию или Переустановить текущую версию. Архив скачивается в RAM, прежнее ядро остаётся в /opt до успешной замены.
  4. Если постоянного хранилища недостаточно, можно включить Режим нехватки места: резервная копия ядра в RAM. Прочитайте подтверждение: при отключении питания копия пропадёт. Не выключайте роутер до завершения.
  5. Дождитесь результата и проверьте подключение. При отказе по ресурсам не удаляйте системные файлы вручную.

Удалить только ядро Xray

На странице Xray нажмите Удалить Xray и подтвердите. VPN остановится, но серверы, подписки, маршруты и настройки останутся, WebUI продолжит работать. Автоматической установки не будет. Чтобы вернуться к VPN, нажмите Проверить версии и явно установите прежнюю или другую совместимую версию, затем подключите сервер.

При прерванной установке сначала прочитайте сообщение BROray. Если RAM-копия потеряна, восстановите ядро явной установкой с этой страницы. Не удаляйте журнал обслуживания вручную.

Нужны свободная RAM с резервом 32 MiB и /opt с резервом 8 MiB. Точный размер нового ядра проверяется после загрузки архива, до изменения старого.

Сохранить и восстановить настройки

  1. На странице «BROray» выберите выгрузку резервной копии.
  2. Для зашифрованной копии задайте пароль не короче восьми символов и сохраните его отдельно.
  3. Перед импортом выберите файл, введите пароль и проверьте предпросмотр.
  4. Подтвердите импорт и дождитесь результата.
  5. Если нужно вернуться назад, используйте отмену импорта из сохранённой предыдущей копии.

Импорт резервной копии 3.2 в 3.5 не поддерживается. Копия содержит сведения доступа к серверам и подпискам: не публикуйте её. Копия без шифрования допустима только при осознанном выборе в интерфейсе.

Если обновление прервалось

Сначала прочитайте состояние операции и журнал. Не отправляйте вторую установку и не удаляйте файлы журнала вручную. BROray использует журнал для восстановления и отката. При доступном терминале начните с безопасных команд просмотра:

/opt/bin/broray version
/opt/bin/broray ctl ping
/opt/bin/broray installer status

Встроенное восстановление вызывается командой /opt/bin/broray ctl recover; вариант --restart применяют только понимая причину остановки и имея способ вернуться к роутеру. Не используйте инструкции с каталогами updater-v5 от 3.2 для 3.5.

Очистка и журналы

Используйте предварительный план очистки на странице BROray. Проверьте, какие именно собственные временные файлы, журналы и копии выбраны. BROray проверяет принадлежность файлов; неизвестный файл не следует удалять вручную ради обхода отказа. Журналы Xray ограничиваются ротацией.

Удаление

Если нужно сохранить данные для последующей установки, выберите соответствующий режим. Через WebUI удаление доступно по локальному IPv4-адресу; внешний адрес KeenDNS для него заблокирован. Через терминал Entware предусмотрена команда:

/opt/bin/broray installer uninstall --keep-data

Удаление может остановить VPN и затронуть связанные маршруты. Заранее сохраните данные и обеспечьте доступ к панели роутера. Полное удаление данных — отдельный режим с явным подтверждением; оно не нужно для обычного обновления 3.5. Не удаляйте Entware, чужие настройки и каталоги вручную.
