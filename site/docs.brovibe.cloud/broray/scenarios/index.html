BROray · 3.5.9 r9 · Stable

Сценарии BROray

Короткие последовательности действий для обычной работы в WebUI 3.5.9.

Подключить первый сервер

  1. Откройте «Серверы» и импортируйте свою ссылку.
  2. Проверьте предпросмотр и добавьте сервер.
  3. Активируйте сервер, затем нажмите «Проверить».
  4. Установите нужные маршруты или настройте политику Keenetic для нужных устройств.

Использовать подписку

  1. Откройте «Подписки» и добавьте URL провайдера.
  2. Запустите обновление и дождитесь результата.
  3. Перейдите к серверам и активируйте нужный узел.
  4. Настройте расписание обновления, если оно необходимо.

При полном успешном обновлении BROray убирает исчезнувшие серверы. Если исчез активный, приложение проверяет замену среди серверов обновлённой подписки. Когда они недоступны, прежнее подключение может сохраняться. Частичный ответ сохраняет прежние записи. Работа с подписками.

Настроить резервирование VPN

  1. Проверьте два или три сервера на странице «Серверы».
  2. Откройте «Резервирование VPN». Выберите основной сервер и первый резерв. Второй резерв можно добавить при необходимости.
  3. Нажмите «Сохранить состав» и включите резервирование.
  4. Если карточка сообщает о сбое, нажмите «Восстановить резервирование» и дождитесь результата.

Если весь состав недоступен, BROray может временно использовать проверенный сервер из общего списка. Когда сервер из состава подтверждает доступность и выполнены условия возврата, BROray возвращается к резервной группе. На Keenetic интерфейс сохраняет имя BROray - mix-auto. Настройки резервирования и автовыбора.

Направить сервис через VPN

  1. Откройте «Маршруты → По доменам». Выберите готовый список или добавьте свой.
  2. Откройте «Подробнее» и проверьте совместимые домены и пропущенные правила.
  3. Нажмите «Включить в Keenetic» и подтвердите. Keenetic создаст доменный список и правило через интерфейс BROray.
  4. Проверьте сайт с устройства этого роутера с его DNS и политикой «По умолчанию». Чтобы убрать правило, нажмите «Отключить» в карточке.

Если у вас набор IP-адресов, откройте «Готовые маршруты» или «Свои маршруты». Для чего нужен каждый вид маршрутов.

Подключить DNS-over-TLS

  1. Откройте «DNS-over-TLS» и отметьте нужные серверы.
  2. Проверьте их доступность и прогноз количества записей.
  3. Примените выбор.
  4. Убедитесь, что управляемые и внешние записи отображаются отдельно.

Открывать WebUI через KeenDNS

  1. Если вы в домашней сети, сначала откройте BROray по адресу роутера на порту 8080. Если доступ есть только через внешнюю панель Keenetic, проверьте варианты восстановления доступа.
  2. Откройте страницу «Keenetic» и блок доступа к WebUI.
  3. Включите адрес и используйте действие «Открыть адрес».
  4. Не выключайте единственный внешний адрес во время удалённой работы без другого способа доступа.

Подробности кнопок — в руководстве WebUI. Ссылки подписок и серверов содержат личные данные: в публичный отчёт их не включают.

Одна подписка: URI, JSON и Clash

  1. Откройте Подписки и добавьте основную ссылку провайдера.
  2. Нажмите Обновить. Включите нужные дополнительные JSON/Clash-форматы в настройках подписки: по умолчанию они выключены.
  3. Откройте список серверов этой подписки. Полные совпадения объединяются; различающиеся настройки сохраняются. На странице «Серверы» варианты доступны в выборе источника.
  4. Если экспорт недоступен или неполон, прочитайте ошибку: прежний список сохранится. При необходимости можно отдельно добавить прямую ссылку JSON или Clash.

Существующие отдельные подписки автоматически не удаляются. Из Clash переносятся серверы, а не rules, DNS и proxy-groups. AmneziaWG сохраняется без подключения через Xray.

JSON и Clash по выбору

В настройках каждой подписки есть независимые переключатели «Дополнительно загружать JSON» и «Дополнительно загружать Clash». Оба по умолчанию выключены, в том числе у прежних подписок без этих настроек. Включите нужные форматы до обновления, если хотите получать явно объявленные дополнительные выгрузки того же источника. Прямая ссылка на JSON или Clash работает независимо от этих переключателей.
