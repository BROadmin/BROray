BROray · 3.5.6 · Stable

Сценарии BROray

Короткие последовательности действий для обычной работы в WebUI 3.5.6.

Подключить первый сервер

  1. Откройте «Серверы» и импортируйте свою ссылку.
  2. Проверьте предпросмотр и добавьте сервер.
  3. Активируйте сервер, затем нажмите «Проверить».
  4. Установите нужные маршруты или настройте политику Keenetic для нужных устройств.

Использовать подписку

  1. Откройте «Подписки» и добавьте URL провайдера.
  2. Запустите обновление и дождитесь результата.
  3. Перейдите к серверам и активируйте нужный узел.
  4. Настройте расписание обновления, если оно необходимо.

Настроить резерв

  1. Добавьте минимум два рабочих подключения.
  2. Проверьте их качество.
  3. На странице «Серверы» настройте автоматическое переключение и правило выбора.
  4. Сохраните настройки и проверьте статус автоматики.

В 3.5.6 смена SNI/Short ID сохраняет ID одного узла при однозначном соответствии. Совпадающие по прочим параметрам старые варианты внутри одной подписки объединяются; ручные записи и другие подписки остаются отдельными. Если узел удалён провайдером, полный успешно разобранный ответ удалит его из BROray. Для исчезнувшего активного узла VPN отключается; включённый автовыбор ищет замену по своим настройкам. Если подходящей замены нет, поиск повторяется после защитного интервала. При выключенном автовыборе выберите сервер вручную. Ручное отключение VPN отменяет поиск.

Направить сервис через VPN

  1. Откройте «Маршруты → Готовые маршруты».
  2. Найдите сервис, скачайте и проверьте набор.
  3. Посмотрите план и выполните установку в Keenetic.
  4. После завершения проверьте, что записи набора присутствуют.

Подключить DNS-over-TLS

  1. Откройте «DNS-over-TLS» и отметьте нужные серверы.
  2. Проверьте их доступность и прогноз количества записей.
  3. Примените выбор.
  4. Убедитесь, что управляемые и внешние записи отображаются отдельно.

Открывать WebUI через KeenDNS

  1. Если вы в домашней сети, сначала откройте BROray по адресу роутера на порту 8080. Если доступ есть только через внешнюю панель Keenetic, используйте включение адреса через терминал.
  2. Откройте страницу «Keenetic» и блок доступа к WebUI.
  3. Включите адрес и используйте действие «Открыть адрес».
  4. Не выключайте единственный внешний адрес во время удалённой работы без другого способа доступа.

Подробности кнопок — в руководстве WebUI. Ссылки подписок и серверов содержат личные данные: в публичный отчёт их не включают.

Одна подписка: URI, JSON и Clash

  1. Откройте Подписки и добавьте основную ссылку провайдера.
  2. Нажмите Обновить. Если страница явно объявляет JSON и Clash того же сайта, BROray загрузит их сам.
  3. Откройте список серверов этой подписки. Полные совпадения объединяются; различающиеся настройки сохраняются. На странице «Серверы» варианты доступны в выборе источника.
  4. Если экспорт недоступен или неполон, прочитайте ошибку: прежний список сохранится. При необходимости можно отдельно добавить прямую ссылку JSON или Clash.

Существующие отдельные подписки автоматически не удаляются. Из Clash переносятся серверы, а не rules, DNS и proxy-groups. AmneziaWG сохраняется без подключения через Xray.
