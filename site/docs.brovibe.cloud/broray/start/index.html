BROray · 3.5.9 r9 · Stable

Первая установка BROray

Установите BROray 3.5.9 r9 на Keenetic или Netcraze с работающим Entware. После установки откройте WebUI BROray в браузере.

Если BROray уже установлен

Для обновления и переустановки используйте WebUI BROray. Перейти к обновлению.

Перед началом

Подключитесь к домашней сети. На роутере нужны работающий Entware, 60 МиБ свободного места в /opt и компонент «Клиент прокси». Как проверить компоненты KeeneticOS.

Если Entware ещё не установлен

Выберите инструкцию производителя для вашей модели. Пример для Keenetic · Пример для Netcraze.

1. Откройте терминал Entware

В веб-терминале Keenetic выполните exec sh из приглашения (config)>. Если входите по SSH в Entware, войдите как root.

Если терминал или загрузка не работают

Для веб-терминала нужны компонент «Интерфейс командной строки в браузере» и доступ OPKG для вашей учётной записи. Команда id -u должна показать 0. Если отсутствует curl или проверка сертификата не проходит, выполните opkg update, затем opkg install curl ca-bundle ca-certificates.

2. Найдите модель и скопируйте команду

Раскройте свою группу, нажмите «Скопировать» и вставьте команду целиком в терминал. Она скачает нужный архив, проверит его и установит BROray.

ARM64 · KN-1012, KN-1811, KN-1812, KN-2312, KN-2710, KN-3811, KN-3812, KN-4110, NC-1812
(
set -eu
if [ -e /opt/bin/broray ] || [ -L /opt/bin/broray ]; then
  echo 'BROray уже установлен. Откройте инструкцию обновления.' >&2
  exit 1
fi
work="$(mktemp -d /tmp/broray-install.XXXXXX)"
trap 'rm -rf -- "$work"' EXIT
cd "$work"
bundle="broray-3.5.9-aarch64-r9.tar.gz"
curl --proto '=https' --tlsv1.2 -fS --connect-timeout 15 --max-time 300 -o "$bundle" "https://api.brovibe.cloud/releases/broray/channels/stable/$bundle"
printf '%s  %s\n' '46d8b63c6e06c90d15c1b0da4e6eddff7fe890310b037b684682413b9d2d2a90' "$bundle" | sha256sum -c -
tar -xzf "$bundle"
"./broray-3.5.9-aarch64/broray" installer install
/opt/bin/broray ctl ping
)

Если модели нет в списке

Выполните opkg print-architecture и выберите группу по архитектуре Entware. Таблица архитектур.

Если установка завершилась ошибкой, сохраните её текст и проверьте причину. Решение проблем.

3. Откройте BROray

Откройте в браузере адрес роутера с портом 8080, например http://192.168.1.1:8080/. Войдите с логином и паролем администратора Keenetic. Подключение первого сервера.

Для входа через KeenDNS проверьте внешний адрес в блоке доступа к WebUI на странице «Keenetic». Настройка доступа через KeenDNS.
