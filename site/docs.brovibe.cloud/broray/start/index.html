BROray · 3.5.9 r9 · Stable

Первая установка BROray

Установите BROray 3.5.9 r9 на Keenetic или Netcraze с работающим Entware. После установки откройте WebUI BROray в браузере.

Если BROray уже установлен

Для обновления и переустановки используйте WebUI BROray. Перейти к обновлению.

1. Подготовьте роутер

Подключитесь к домашней сети. Убедитесь, что Entware работает и на разделе /opt свободно не менее 60 МиБ. Для подключения VPN нужен компонент KeeneticOS «Клиент прокси». Администратор Keenetic используется для входа в WebUI, а для установки нужны права root в Entware. Требования и компоненты KeeneticOS.

Если Entware ещё нет, сначала установите его по инструкции производителя для вашей модели. Пример для Keenetic · Пример для Netcraze.

2. Откройте терминал Entware

Откройте SSH-сеанс Entware или штатный веб-терминал Keenetic. Для веб-терминала нужен компонент «Интерфейс командной строки в браузере» и доступ OPKG для вашей учётной записи. Из приглашения (config)> выполните exec sh. Продолжайте, когда открылась оболочка Entware. Команда id -u должна вывести 0.

3. Выберите сборку

Выполните opkg print-architecture. Выберите код сборки по архитектуре Entware. В списке ищите строку архитектуры устройства, например aarch64-3.10. Запись all обозначает общие пакеты. Архитектуры и модели роутеров.

Архитектура EntwareКод сборки
ARM64 (AArch64)aarch64
ARMv7, 32 битаarmv7
MIPS Little Endianmipsel
MIPS Big Endianmips

4. Скачайте и установите BROray

Если curl отсутствует или на роутере нет актуальных корневых сертификатов, выполните opkg update, затем opkg install curl ca-bundle ca-certificates. В первой строке следующего блока укажите выбранный код сборки. Запустите весь блок в терминале роутера.

arch=aarch64
(
set -eu
case "$arch" in
  aarch64) expected=46d8b63c6e06c90d15c1b0da4e6eddff7fe890310b037b684682413b9d2d2a90 ;;
  armv7) expected=06d44afdb843fc6e888b944371506124ea39d4c0353aaee2d3c60f3aeffd3c57 ;;
  mipsel) expected=147cd9146fc86e06600859ab7adc3a707367dc428bab98ce1ac0325e627986c1 ;;
  mips) expected=6040bac59483f52db4fd64ee5b22ca729571478c94f225d4326ad80b90ec3452 ;;
  *) echo 'Выберите архитектуру из таблицы.' >&2; exit 1 ;;
esac
if [ -e /opt/bin/broray ] || [ -L /opt/bin/broray ]; then
  echo 'BROray уже установлен. Откройте инструкцию обновления.' >&2
  exit 1
fi
work="$(mktemp -d /tmp/broray-install.XXXXXX)"
trap 'rm -rf -- "$work"' EXIT
cd "$work"
bundle="broray-3.5.9-${arch}-r9.tar.gz"
curl --proto '=https' --tlsv1.2 -fS --connect-timeout 15 --max-time 300 -o "$bundle" "https://api.brovibe.cloud/releases/broray/channels/stable/$bundle"
printf '%s  %s\n' "$expected" "$bundle" | sha256sum -c -
tar -xzf "$bundle"
"./broray-3.5.9-${arch}/broray" installer install
/opt/bin/broray version
/opt/bin/broray ctl ping
)

Если команда вернула ошибку, сохраните её текст и остановитесь на этом шаге. При несовпадении SHA-256 или архитектуры повторно сверяйте архив и модель. Если на роутере осталась ветка 3.2, сохраните данные и разберите её состояние до первой установки 3.5. Решение проблем установки и входа.

5. Войдите в WebUI

Откройте BROray по локальному адресу роутера с портом 8080, например http://192.168.1.1:8080/. Войдите с логином и паролем администратора Keenetic. В WebUI проверьте состояние Xray. Затем добавьте сервер или подписку, проверьте выбранный сервер и нажмите «Подключить». Как подключить первый сервер.

Для входа через KeenDNS проверьте внешний адрес в блоке доступа к WebUI на странице «Keenetic». Настройка доступа через KeenDNS.
