BROray · 3.5.9 · Stable

Обновление BROray до 3.5.9 через WebUI

Четыре шага для уже установленного BROray 3.5.

Как обновиться через WebUI

Обновление на BROray 3.5.9 выполняется через WebUI установленной версии 3.5.0–3.5.8. Обновитель скачивает сборку для вашего роутера из подписанного канала Stable.

  1. Откройте действующий WebUI и перейдите на страницу BROray.
  2. Скачайте резервную копию настроек.
  3. Нажмите Проверить обновление и убедитесь, что предлагается 3.5.9.
  4. Нажмите Установить обновление. Дождитесь завершения, войдите снова и проверьте версию на странице BROray.

Если уже установлена 3.5.9, скачайте резервную копию. На странице BROray нажмите Проверить обновление, затем Переустановить. После завершения войдите снова. В исправленной сборке команда удаления подписки отправляется в штатную очередь.

Встроенное обновление доступно для ветки 3.5. Переход с 3.2 через WebUI не поддерживается.

Где открыть WebUI

Используйте привычный адрес BROray в домашней сети или адрес KeenDNS. Для входа нужны данные администратора роутера.
