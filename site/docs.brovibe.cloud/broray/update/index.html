BROray · 3.5.10 r15 · Stable

Обновление BROray через WebUI

Как обновиться с 3.5.9 и проверить VPN после установки 3.5.10.

Если BROray на роутере ещё нет, начните с первой установки.

Как обновиться через WebUI

Обновитель скачивает сборку для вашей архитектуры из подписанного Stable и проверяет её.

  1. Откройте страницу BROray в WebUI и скачайте резервную копию настроек.
  2. Нажмите Проверить обновление. Если предлагается 3.5.10, нажмите Установить обновление.
  3. Дождитесь завершения, войдите снова и проверьте 3.5.10 r15 на странице BROray. На странице Серверы проверьте активный VPN и резервирование.

Если уже установлена 3.5.10, кнопка Переустановить текущую версию позволяет установить доступную ревизию из Stable.

Встроенное обновление доступно в ветке 3.5. При переходе с 3.2 воспользуйтесь инструкцией по подготовке к чистой установке.

Где открыть WebUI

Используйте привычный адрес BROray в домашней сети или адрес KeenDNS. Для входа нужны данные администратора роутера.

Если у BROray ещё нет отдельного адреса KeenDNS, откройте локальный WebUI и включите адрес в блоке доступа к WebUI на странице «Keenetic». Проверьте внешний адрес, пока локальная страница открыта. Как открыть BROray через KeenDNS.
