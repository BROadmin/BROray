WebUI BROray 3.1.1

Фактический интерфейс Stable 3.1.1-r12. Описание ниже собрано из HTML, JavaScript и CGI точного опубликованного app-bundle, а не из планов или исходников соседних кандидатов.

WebUI-3.1.1-r12c01

modules.html присутствует в архиве как служебный compatibility/redirect-файл, но отдельного пункта «Совместимость» в пользовательском меню Stable 3.1.1 нет.

Общие элементы интерфейса

  • на компьютере боковое меню можно свернуть; на мобильном оно открывается поверх страницы;
  • в меню отображается текущий пользователь KeeneticOS и есть кнопка Выйти;
  • доступно управление темой интерфейса;
  • кнопка Поддержать проект открывает встроенное окно поддержки;
  • опасные действия используют фирменные окна подтверждения, а для полного удаления BROray требуется точная контрольная фраза.

Вход

Экран входа содержит поля Логин и Пароль, кнопку Показать пароль и кнопку Войти. После успешной проверки создаётся WebUI-сессия; защищённые страницы используют её через session API.

Главная

Это сводный экран. Он показывает состояние модулей и ведёт на соответствующие страницы, но не дублирует их действия.

Серверы

Активный сервер, общее число серверов и качество.

Подписки

Состояние подписок, число включённых и количество полученных серверов.

Маршруты

Число установленных наборов, состояние обновления и DNS-over-TLS.

Keenetic

Состояние управляемого прокси-интерфейса, связь и рабочее состояние.

Xray

Состояние процесса, версия и конфигурация.

BROray

Версия приложения и состояние обновления.

В разметке релиза есть служебная кнопка refresh-status, но она скрыта (hidden) и не является обычным пользовательским действием на Главной.

Серверы

Страница объединяет активное подключение, сохранённые узлы, импорт, ручные/плановые проверки качества и автопереключение.

Импорт сервера

Форма WebUI сначала разбирает и проверяет URI. В точном релизном JavaScript она распознаёт:

VLESSVMessTrojanHysteria2Shadowsocks / ss://

За одну предварительную проверку принимается до 50 URI. Кнопка формы сначала подписана Проверить конфигурацию; после успешной проверки пользователь подтверждает импорт. Это описание именно поведения формы Stable 3.1.1, а не заявление о совместимости каждого возможного сочетания транспорта и сервера.

Действия с серверами

  • у активного сервера — Проверить и Отключить VPN;
  • у каждого сохранённого сервера — Проверить, Подключить (если он не активен), Подробнее/Скрыть;
  • в раскрытых подробностях доступно Удалить сервер;
  • для списка — Обновить данные и Проверить все.

Качество и автоматическое переключение

Релиз показывает пинг, джиттер, оценку качества/свежести, время и источник последней проверки. При зафиксированном методе отображается HTTPS через Xray + ICMP ping.

Отдельная настройка автоматической проверки качества позволяет включить расписание и выбрать интервал: 30 минут, 1 час, 3 часа или 6 часов.

В блоке Автоматическое переключение доступны:

  • включение/выключение автовыбора;
  • правило: Лучшее качество, Минимальный пинг или Предпочтительный сервер;
  • предпочтительный сервер;
  • число ошибок до переключения (1–10);
  • защитный интервал после переключения (1–120 минут);
  • минимальное качество: Отличное, Хорошее, Приемлемое или Любое доступное;
  • состояние сервиса, число ошибок, последнее переключение и причина.

В коде релиза прямо указано: при подтверждённой потере связи BROray проверяет резервные серверы реальным HTTPS-запросом. Ручное «Отключить VPN» выключает автовыбор; вручную остановленный Xray автоматически не запускается.

Подписки

Форма создания/редактирования содержит поля Название, Интервал, минут, URL подписки и переключатели Подписка активна, Автообновление включено, Обновить после добавления.

На карточке каждой подписки релизный WebUI умеет:

  • Обновить сейчас;
  • Показать серверы / Скрыть серверы;
  • Изменить;
  • Включить / Отключить подписку;
  • Включить автообновление / Отключить автообновление;
  • Удалить.

Карточка также показывает количество серверов, интервал, последнее и следующее обновление, результат синхронизации, предупреждения и последнюю ошибку.

DNS-over-TLS

Страница читает фактическую конфигурацию Keenetic и показывает каталог DoT вместе с уже существующими DoT/DoH-записями.

  • Проверить выбранные — выполняется TLS/SNI-проверка выбранных DoT;
  • Установить в Keenetic — доступно только после необходимых проверок и при допустимой ёмкости Keenetic;
  • Обновить состояние — перечитывает фактическую конфигурацию;
  • Удалить записи BROray — проходит через отдельный delete-gate.

При установке окно подтверждения прямо сообщает, что сторонние записи не удаляются и не переходят под управление BROray. При удалении релиз предупреждает: удаляются точные выбранные записи, а невыбранные DoT/DoH сохраняются. Интерфейс контролирует общий лимит защищённых DNS; при отсутствии иного значения используется максимум 8.

Маршруты

В Stable 3.1.1 это три самостоятельных пользовательских экрана.

Обзор

Показывает управляемый интерфейс, число маршрутов BROray и общих маршрутов, текущую операцию, статистику пользовательских и готовых наборов. Доступна кнопка Обновить состояние.

Свои маршруты

Загрузка BAT обрабатывается как данные маршрутов. В релизе общий размер выбранных файлов ограничен 2 МиБ. Перед сохранением выполняется preview/валидация.

  • Загрузить BAT;
  • для существующего набора: Проверить, основное действие по состоянию (Установить/Обновить/Восстановить/Продолжить), Заменить файл, Удалить;
  • для нового или заменяемого набора: Проверить и затем Создать набор / Сохранить замену.

Готовые маршруты

В релизе ровно 10 встроенных наборов:

TelegramWhatsAppYouTubeChatGPTFacebookInstagramMetaTikTokSpeedtestWikipedia

Карточки проходят пошаговый цикл: проверка обновления → загрузка маршрутов → подготовка к установке → действие в Keenetic (установка/обновление/восстановление). Для установленного набора доступно удаление, для остановленной операции — продолжение, также есть подробности.

Общее окно операции

Для операций с маршрутами есть единый прогресс: текущий маршрут, выполнено/всего, сворачивание окна, Остановить после текущего маршрута и Продолжить при поддерживаемом resumable-состоянии.

Keenetic

Страница сравнивает ожидаемое и фактическое состояние управляемого SOCKS5 ProxyN.

Проверяются: существование интерфейса, принадлежность BROray, протокол SOCKS5, адрес Xray, описание, доступность прокси Xray, связь, подключение и рабочее состояние.

Фактические кнопки релиза:

Проверить подключение к Xray Обновить Создать Восстановить Синхронизировать описание Удалить

Адрес WebUI через KeenDNS

На той же странице есть отдельный блок состояния публикации WebUI. Он показывает публичный адрес, локальный адрес и режим KeenDNS. В зависимости от состояния доступны:

  • Включить или динамическое Восстановить адрес;
  • Выключить;
  • Открыть адрес;
  • Копировать адрес.

При выключении релиз предупреждает, что текущая сессия через KeenDNS прервётся, но локальный адрес WebUI останется доступен в домашней сети.

Xray

Страница показывает процесс, PID, локальный SOCKS и его доступность, архитектуру, свободное место, а также путь, размер и SHA-256 рабочего конфигурационного файла.

Процесс и конфигурация

ЗапуститьПерезапуститьОстановитьПроверить

Проверить относится к рабочей конфигурации. Перезапуск предупреждает о кратком разрыве соединения, остановка — о недоступности прокси до повторного запуска.

Выбор версии Xray

  • Проверить версии получает официальный каталог;
  • пользователь выбирает Версию для установки;
  • переключатель Показать предварительные версии расширяет список;
  • показывается статус совместимости конкретной версии;
  • кнопка динамически становится Установить VERSION или Переустановить VERSION;
  • отдельно есть Переустановить текущую версию;
  • непроверенная, предварительная версия и понижение требуют отдельных подтверждений.

Диагностика

Запустить диагностику формирует список проверок с количеством успешных, предупреждений и ошибок. Установка/переустановка Xray отслеживается как фоновая операция с журналом и результатом.

BROray

Обновление и переустановка

  • Проверить обновление;
  • Установить обновление — при незавершённом переходе кнопка может стать Завершить обновление;
  • Переустановить текущую версию.

Безопасная очистка

Перед удалением файлов сначала строится точный план кнопкой Проверить очистку, затем становится доступно Очистить. Пользователь выбирает категории:

  • временные файлы и незавершённые загрузки;
  • старые резервные копии — сохраняются последние три копии каждого управляемого типа;
  • копии отката маршрутов — сохраняются три последних набора каждого типа;
  • старые журналы — только архивы/ротации старше семи дней.

Восстановление и удаление

В релизной разметке присутствует действие восстановления последней доступной резервной копии, но кнопка включается только когда backend подтверждает доступность подходящей копии.

Опасная зона содержит Удалить BROray и Удалить полностью. Полное удаление требует точной контрольной фразы и удаляет программу, настройки, подписки, серверы, маршруты, owned ProxyN, KeenDNS HTTP Proxy и служебные данные.
