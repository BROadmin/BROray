Установка BROray-Light

Подготовьте Entware, скачайте проверенный архив для роутера и откройте WebUI.

Stable 3.5.10

1. Требования и архитектура

Нужен Keenetic или Netcraze с работающим Entware, доступом по SSH от root и корректными датой, DNS и HTTPS. На накопителе должен быть смонтирован /opt. Каталог /opt/etc/init.d должен принадлежать root и запрещать запись группе и остальным пользователям.

В Entware shell выполните opkg print-architecture. Выберите строку, совпадающую с архитектурой Entware.

Архитектура пакетов EntwareАрхив
aarch64-3.10broray-light-3.5.10-linux-arm64.tar.gz
armv7-3.2broray-light-3.5.10-linux-armv7.tar.gz
mipsel-3.4broray-light-3.5.10-linux-mipsel.tar.gz
mips-3.4broray-light-3.5.10-linux-mips.tar.gz

Работу на устройстве подтвердили для ARM64. Для остальных архитектур подтверждены сборки. ARMv7 требует VFPv3. На MIPS проверьте требования Xray.

2. Entware и накопитель

Если OPKG уже работает, сохраните существующий Entware. Для первой настройки используйте руководство Keenetic Community и накопитель с доступом только для администратора. Сохраните нужные файлы перед форматированием.

Сообщение unsafe directory /opt/etc/init.d означает, что для постоянной установки нужен доверенный том с корректным владельцем и правами каталога запуска.

3. SSH и контрольные суммы

На компьютере скачайте выбранный архив, SHA256SUMS и SHA256SUMS.binaries. Сравните SHA-256 архива со строкой для этого файла. В Linux и macOS можно выполнить shasum -a 256 ИМЯ_АРХИВА, в Windows PowerShell — Get-FileHash -Algorithm SHA256 -LiteralPath ИМЯ_АРХИВА.

Скопируйте проверенный архив в отдельный каталог внутри /tmp на роутере. В каталоге распаковки нужно место под архив и извлечённый бинарник. Войдите по SSH в Entware shell от root и перейдите в этот каталог.

4. Чистая установка

Если установлена shell-версия Light, сначала выполните переход. При обнаружении старой службы Light или полного BROray установщик прерывает работу.

В примере выбран ARM64. Подставьте имя вашего архива, а вместо SHA256_БИНАРНИКА — 64 шестнадцатеричных символа из строки нужной архитектуры в SHA256SUMS.binaries.

tar -xzf broray-light-3.5.10-linux-arm64.tar.gz
./broray-light install --sha256 SHA256_БИНАРНИКА

Установщик проверяет SHA-256, запускает S24broray-light и ждёт готовности. После успешной установки проверьте службу.

/opt/broray-light/bin/broray-light ready --version 3.5.10

5. WebUI и Xray

  1. Из домашней сети откройте http://LAN-IP:8080/. Для доступа из другой сети используйте https://brolight.ДОМЕН-KEENDNS/ с зарегистрированным KeenDNS или CrazeDNS этого роутера.
  2. Войдите с учётной записью Keenetic, которой разрешено управление роутером.
  3. На Главной откройте Ядро Xray → Установить. Затем добавьте сервер или подписку, проверьте сервер и нажмите Активировать.

Оба способа доступа включаются при установке. Если KeenDNS или CrazeDNS ещё запускается, используйте порт 8080. Когда сервис домена будет готов, Light повторит настройку HTTPS. Если имя brolight уже занято чужим правилом, Light оставит это правило владельцу.

Переход с shell Light 1.x и 2.0

  1. Скопируйте на компьютер каталоги /opt/broray-light/config, /opt/broray-light/servers и /opt/broray-light/subscriptions. Сохраните исходные ссылки, порядок, исключения, активный сервер и параметры резерва. Храните копию в закрытом месте.
  2. Выполните штатное удаление старой версии по руководству shell Light. Проверьте, что остановлены старый updater и служба. Если за старым интерфейсом остались зависимости, сначала перенесите их в Keenetic и повторите штатную очистку.
  3. Установите 3.5.10 по шагам выше. Добавьте подписки и ручные серверы, восстановите порядок, исключения и настройки резерва, затем активируйте нужный сервер. Каталоги shell-версии пригодятся как резервная копия для возврата на прежний выпуск.

Настройте первое соединение

Выберите сервер из подписки или добавьте его вручную.
