BROray-Light · 3.5.10 · Stable

Установка BROray-Light 3.5.10 по шагам

Откройте терминал Entware на роутере, вставьте готовый блок команд и войдите в BROray-Light.

С чего начать

  • Ставите впервые — начните с подготовки роутера. Если Entware уже работает, откройте его терминал.
  • Стоит Light 1.x или 2.0 — сначала сохраните настройки и подготовьте переход.
  • Стоит Light на Go — откройте инструкцию по обновлению.

1. Подготовьте роутер

  1. Войдите в основную панель Keenetic или Netcraze и убедитесь, что на роутере работает интернет. Проще начать из домашней сети. Если у вас только облачный адрес панели, откройте веб-терминал на шаге 2.
  2. В «Управление» → «Настройки системы» → «Изменить набор компонентов» проверьте «Поддержка открытых пакетов» (opkg). Если хотите направлять трафик устройств через Light, нужен также «Клиент прокси» (proxy). Для внешнего адреса WebUI нужен настроенный KeenDNS или CrazeDNS.
  3. Если Entware ещё не установлен, настройте его по инструкции Keenetic или руководству Netcraze на русском. При установке на USB с ext4 нужна поддержка Ext. Работающий Entware можно использовать как есть.

Установите только недостающие компоненты. Панель может временно отключиться, если KeeneticOS обновится и роутер перезагрузится.

2. Откройте терминал Entware

Выберите любой из двух способов. Команды ниже выполняются в терминале роутера, где приглашение обычно заканчивается символом #.

Вариант А. В браузере

  1. Войдите в основную панель роутера как администратор. При удалённой установке подойдёт уже настроенный облачный адрес панели.
  2. В настройках компонентов проверьте наличие «Интерфейс командной строки в браузере».
  3. На странице «Менеджер пакетов OPKG» включите «Доступ» для своей учётной записи администратора и сохраните изменения.
  4. В верхней части панели нажмите шестерёнку и выберите «Интерфейс командной строки». Если видите (config)>, введите:
exec sh

Когда появится строка с #, переходите к шагу 3. Если по-прежнему видите (config)>, проверьте, что Entware установлен и для вашей учётной записи разрешён доступ к OPKG.

Вариант Б. По SSH из домашней сети

  1. В PuTTY, Termius или другом SSH-клиенте укажите локальный адрес роутера, например 192.168.1.1.
  2. Укажите порт Entware. Обычно это 222, если встроенная служба SSH роутера занимает 22. Если настроен другой порт, используйте его.
  3. Войдите как root с паролем Entware. В терминале символы пароля обычно не отображаются. Если вы попали в (config)>, используйте exec sh при включённом доступе к OPKG.

Облачный адрес панели может работать без доступа по SSH. Тогда используйте вариант А.

3. Установите curl и сертификаты

Если curl уже скачивает файлы по HTTPS, переходите к шагу 4. Иначе скопируйте команду, вставьте в терминал роутера, нажмите Enter и дождитесь окончания:

opkg update && opkg install ca-bundle ca-certificates curl

Если opkg не найден или установка пакетов завершилась ошибкой, вернитесь к шагам 1 и 2.

4. Установите BROray-Light

Нажмите кнопку копирования рядом с блоком. Вставьте весь блок в терминал роутера и нажмите Enter. Он сам определит архитектуру Entware, скачает архив с GitHub, сверит контрольные суммы и запустит установщик. В блоке ничего подставлять не нужно.

(
  set -eu
  fail() { printf '%s\n' "$*" >&2; exit 1; }
  [ "$(id -u)" = 0 ] || fail 'Откройте терминал Entware с правами root.'
  command -v opkg >/dev/null || fail 'Команда opkg не найдена. Проверьте, что открыт терминал Entware.'
  command -v curl >/dev/null || fail 'Сначала выполните шаг «Установите curl и сертификаты».'

  arches=$(opkg print-architecture) || fail 'Не удалось узнать архитектуру Entware.'
  arch=$(printf '%s\n' "$arches" | awk '$1 == "arch" && $2 != "" && $2 != "all" && $2 != "noarch" && !seen[$2]++ { print $2 }')
  case "$arch" in
    aarch64-3.10)
      target=arm64
      archive_sha=ecbe29a5779fad84b96114cdd24e184c4236bfdc0980ca159f48c6e69c8f508d
      binary_sha=60c23462d7cd2bb6b2a8087f2722517c2189ec8b1ad01f080046f9841c57f5c8 ;;
    armv7-3.2)
      target=armv7
      archive_sha=ab1c39eeee02938ea97008eab88383975677c6e2b997621cddbec04f04f7fe3f
      binary_sha=942147ec1e18c09548bea71ab1a302987e05acde0bd578e75937597b674fbccd ;;
    mipsel-3.4)
      target=mipsel
      archive_sha=e39d6a04ce8887293d44c401fc11f5a48f3076c9aea089b77a04eec13f975846
      binary_sha=e3311365f78c4ade55e872192bfa9ffe3656dd8e064c98576ae20d512f145b6d ;;
    mips-3.4)
      target=mips
      archive_sha=f4b1572cd383b826aa6d1216c270affd06d13dd1ee44c93de4a3e2756e136ff6
      binary_sha=86fd3fa300da1a850011f83c90c1ece8ffd240c20ba02889570098c3e6ac217b ;;
    *) fail 'Не удалось выбрать архив. Выполните opkg print-architecture и сверьтесь с таблицей совместимости.' ;;
  esac

  work=$(mktemp -d /tmp/broray-light-install.XXXXXX) || fail 'Не удалось создать временный каталог в /tmp.'
  trap 'rm -f "$work/release.tar.gz" "$work/broray-light"; rmdir "$work"' 0
  trap 'exit 1' HUP INT TERM
  base=https://github.com/BROadmin/BROray-Light/releases/download/v3.5.10
  printf 'Скачиваем BROray-Light 3.5.10 для %s…\n' "$target"
  curl -q -fsSL --proto '=https' --proto-redir '=https' --connect-timeout 10 --max-time 120 \
    -o "$work/release.tar.gz" "$base/broray-light-3.5.10-linux-$target.tar.gz" ||
    fail 'Не удалось скачать архив. Проверьте интернет и время на роутере.'
  printf '%s  %s\n' "$archive_sha" "$work/release.tar.gz" | sha256sum -c - ||
    fail 'Контрольная сумма архива не совпала. Скачанный файл удалён.'
  tar -xzf "$work/release.tar.gz" -C "$work" broray-light ||
    fail 'Не удалось извлечь установщик. Проверьте свободное место в /tmp.'
  printf '%s  %s\n' "$binary_sha" "$work/broray-light" | sha256sum -c - ||
    fail 'Контрольная сумма установщика не совпала.'
  "$work/broray-light" install --sha256 "$binary_sha" ||
    fail 'Установщик завершился с ошибкой. Посмотрите сообщение выше.'
  printf '%s\n' 'BROray-Light 3.5.10 установлен. Откройте интерфейс на порту 8080.'
)

Для установленного shell Light сначала выполните переход с прежней версии. Если на роутере уже есть полный BROray, установщик Light остановится.

5. Дождитесь результата

Оставьте терминал открытым. При успехе вы увидите «BROray-Light 3.5.10 установлен». После этого можно открыть WebUI.

Что появилосьЧто сделать
opkg не найден или виден (config)>Снова откройте терминал Entware.
Архив не скачался или не совпала контрольная суммаПроверьте интернет и дату на роутере, затем обновите сертификаты и повторите установку.
Не удалось выбрать архивВведите opkg print-architecture и сверьте результат с таблицей архитектур.

6. Откройте WebUI и подключите сервер

Из домашней сети

Добавьте :8080 к локальному IP-адресу роутера. Если панель находится на 192.168.1.1, введите в браузере http://192.168.1.1:8080/.

По KeenDNS или CrazeDNS

Если у роутера уже есть облачный домен, добавьте к нему спереди brolight. и откройте адрес по HTTPS. После установки Light настраивает публикацию автоматически. Если адрес ещё не открывается, проверьте настройки внешнего доступа или откройте порт 8080 из домашней сети.

Вход и первое подключение

  1. Войдите с логином и паролем администратора роутера, как в основной панели. У root свой пароль Entware для SSH.
  2. На странице «Главная» в разделе «Xray» нажмите «Проверить обновление», затем «Установить» и подтвердите установку ядра.
  3. Если у вас ссылка на сервер, откройте «Серверы», вставьте её и нажмите «Добавить сервер». Для ссылки на подписку откройте «Подписки», нажмите «Добавить подписку» после заполнения формы и «Обновить» в добавленной подписке.
  4. На странице «Серверы» нажмите «Проверить» рядом с нужным сервером, затем «Активировать». Имя выбранного сервера появится на Главной.

Если хотите направить трафик устройств через сервер, включите управление интерфейсом Keenetic и выберите созданный интерфейс в политике подключений роутера.

Переход с shell Light 1.x и 2.0

  1. Сохраните ссылки на серверы и подписки, их порядок, исключения и имя активного сервера. Скопируйте на компьютер каталоги /opt/broray-light/config, /opt/broray-light/servers и /opt/broray-light/subscriptions. Храните резервную копию в закрытом месте.
  2. Удалите прежний Light по руководству shell-версии. Если удаление остановилось из-за используемого интерфейса, проверьте его в настройках Keenetic и завершите штатную очистку.
  3. Установите 3.5.10, заново добавьте серверы и подписки и восстановите нужный порядок.

Архитектуры и ручная установка

Готовый блок проверяет архитектуру сам. Таблица нужна, если вы скачиваете файлы вручную или выясняете причину ошибки. Название архитектуры можно посмотреть командой opkg print-architecture.

Архитектура пакетов EntwareАрхив
aarch64-3.10ARM64
armv7-3.2ARMv7
mipsel-3.4MIPSEL
mips-3.4MIPS

Аппаратная приёмка ARM64 выполнена для исходной сборки 3.5.10. Обновлённая сборка проверена в Linux и браузере. ARMv7 требует VFPv3. Для MIPS и MIPSEL проверьте совместимость Xray.
