WebUI

Интерфейс BROray-Light

Управление соединением, серверами и подписками.

Три страницы

  • Главная — состояние соединения, Keenetic, резерв, Xray и обновление Light.
  • Серверы — импорт, проверка, активация, порядок и удаление профилей.
  • Подписки — добавление, синхронизация и удаление источников.

Вход

Используйте учётную запись Keenetic с правами управления. В домашней сети откройте порт 8080 своего роутера, извне — HTTPS-адрес с поддоменом brolight. Инструкция доступа.

Главная

  • Keenetic — состояние управляемого прокси-интерфейса. После создания назначьте этот интерфейс нужной политике через Keenetic. При сохранённой квитанции нажмите Повторить очистку после снятия зависимостей от интерфейса.
  • Резервирование — включение автопереключения, порог ошибок и пауза после переключения. Очерёдность берётся со страницы «Серверы».
  • Ядро Xray — проверка и установка закреплённой версии. BROray-Light — проверка и применение подписанного обновления приложения.
  • Проект и поддержка — сайт и документация, GitHub, новости и обсуждение в Telegram, ссылка для поддержки проекта через CloudTips.

Серверы

Вставьте ссылку и нажмите Добавить сервер. Для каждой записи доступны просмотр параметров, проверка, активация, переименование, перемещение, исключение из автопереключения и удаление. Поля раздела «Параметры» помогают проверить настройки профиля.

Кнопка Удалить все, кроме активного запрашивает подтверждение. Активная запись и работающее соединение сохраняются, определения подписок остаются в списке. Если подписка по-прежнему отдаёт удалённые профили, они могут вернуться после следующего обновления источника. Кнопка доступна, когда есть активная запись и хотя бы один другой сервер.

Подписки

Добавьте имя и HTTPS-ссылку. Light читает списки ссылок в виде текста и Base64, объединяет одинаковые профили и сохраняет связи с их источниками. Для повторной загрузки нажмите Обновить.

После успешной синхронизации профиль, который больше не отдаёт ни одна подписка и который не добавлен вручную, удаляется. При удалении подписки сохраняются профили из другой подписки и добавленные вручную. Ошибка загрузки сохраняет предыдущий каталог.

Когда подтверждённое обновление или удаление подписки убирает активный профиль, Light останавливает старое соединение и проверяет оставшиеся записи по порядку. Если рабочей замены нет, соединение остаётся остановленным.
