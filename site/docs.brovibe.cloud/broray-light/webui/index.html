WebUI BROray-Light 2.0.0

Фактический интерфейс публичного Stable 2.0.0. Описание собрано из точного опубликованного app-bundle, поэтому здесь нет функций полного BROray, которых Light не содержит.

2.0.0-r1
Источник проверки

broray-light-app-2.0.0-r1.tar.gz · SHA-256 fb7fc533cb7e41d4ea1ea25fb15b7eb0b8e878bb7e75dbbd7b849b18ddc54c9c.

Внутренний app/web-new/build.json подтверждает продукт BROray-Light 2.0.0, release/candidate 2.0.0-r1 и ровно три пользовательские страницы: home, servers, subscriptions.

Открыть релиз v2.0.0

Что реально есть в меню

ЭкранЧто находится внутри
ВходЛогин, пароль, показать/скрыть пароль и вход.
ГлавнаяАктивный сервер, автопереключение, Keenetic, Xray и обновление BROray-Light.
СерверыДобавление VLESS, проверка/активация/удаление, порядок резервов и настройки автопереключения.
ПодпискиДобавление VLESS-подписок, ручное и автоматическое обновление, удаление.

В Light 2.0.0 нет отдельных страниц Keenetic, Xray, Маршруты или DNS-over-TLS. Управление Keenetic и Xray находится на Главной.

Вход

Экран содержит поля Логин и Пароль, кнопку Показать пароль и Войти. При HTTP 401 страницы возвращают пользователя на экран входа.

Локальный WebUI работает на http://LAN-IP-РОУТЕРА:8080/. Для публикации через KeenDNS релизный lifecycle использует имя brolight, поэтому адрес имеет вид https://brolight.ВАШ-ДОМЕН-KEENDNS/.

Главная

Главная — единственная системная страница Light. На ней пять рабочих карточек.

Активный сервер

Показываются имя/ID активного сервера и состояние соединения: работает оно или нет.

Автопереключение

Показывается состояние резервного переключения и ссылка на страницу Серверы для настройки порядка узлов.

Keenetic

Показываются имя интерфейса и его состояние. Доступны:

НастроитьИсправитьОбновить статус

Если интерфейс уже исправен, кнопка восстановления становится недоступной и отображается как Исправно. Кнопки удаления ProxyN на Главной Light 2.0.0 нет.

Xray

Показываются текущая версия и состояние процесса. После Проверить обновление открывается официальный список версий:

  • селектор Версия Xray;
  • Показывать предварительные версии;
  • статус совместимости: проверена / не проверена / несовместима именно с этой сборкой Light;
  • динамическая кнопка Установить VERSION или Переустановить VERSION.

Непроверенная версия, prerelease, downgrade и переустановка текущей версии требуют отдельных подтверждений. После установки список сбрасывается и требует новой проверки. В WebUI Light 2.0.0 нет ручных кнопок Запустить/Остановить/Перезапустить Xray.

BROray-Light

Показываются версия и канал релиза. Доступны Проверить обновление и Обновить, если Stable-канал сообщает о новой версии.

Серверы

Добавление VLESS

Поле принимает только ссылку vless://…. WebUI прямо предупреждает, что повторное добавление уже сохранённого сервера блокируется сравнением нормализованных параметров VLESS.

Кнопка: Добавить сервер.

Карточка сервера

Показываются имя, активность, адрес/порт, VLESS, network/security и результат последней проверки. Доступны:

  • ↑ Переместить выше и ↓ Переместить ниже — этот порядок используется резервным переключением;
  • Проверить;
  • Активировать (для активного сервера кнопка становится неактивной Активен);
  • Удалить;
  • флажок Не использовать в автопереключении.

Результат проверки содержит доступность, HTTP-статус/задержку при успехе либо причину/этап ошибки.

Автопереключение

Это детерминированный порядок, а не рейтинговая система. Настройки:

  • Включить автопереключение;
  • Ошибок до переключения: 1–10, по умолчанию 3;
  • Пауза после переключения в секундах, по умолчанию 600;
  • порядок серверов задаётся стрелками ↑/↓;
  • отдельные серверы можно исключить из резервного выбора;
  • Сохранить настройки.

Состояния, которые реально показывает код: выключено, активный сервер работает, обнаружены ошибки соединения, сервер автоматически переключён, доступная замена не найдена, ожидание первой проверки.

Подписки

Новая подписка

Форма содержит только Название и Ссылка подписки. При создании WebUI сразу запрашивает обновление содержимого. На странице прямо указано: импортируются только VLESS, а URL хранится как секрет и не показывается в списке.

Кнопка: Добавить подписку.

Карточка подписки

Показываются имя, число серверов, последнее обновление и последняя ошибка. Доступны:

  • Обновить;
  • Удалить — подтверждение предупреждает об удалении подписки и полученных из неё серверов;
  • блок Автообновление: включение, интервал 5–10080 минут и Сохранить автообновление;
  • время следующего автоматического обновления.

В релизном WebUI Light 2.0.0 нет кнопок «Изменить подписку», «Отключить подписку» или «Показать серверы», которые есть в полном BROray.

Чего в WebUI Light 2.0.0 нет
  • отдельной страницы Keenetic;
  • отдельной страницы Xray;
  • маршрутов и DNS-over-TLS;
  • ручных Start/Stop/Restart Xray;
  • рейтингов и истории качества серверов;
  • плановой проверки качества всех серверов;
  • редактирования/включения/отключения подписки как отдельной карточечной операции.
