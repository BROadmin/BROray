Справочник

Технические сведения

Архитектуры, протоколы, хранение данных и границы проверки.

Архитектуры и размер

Архивы Linux доступны для ARM64, ARMv7, MIPSEL softfloat и MIPS softfloat. Архив приложения занимает примерно 3,1–3,3 МиБ, установленный бинарник — 7,6–8,9 МиБ. Для ядра Xray нужно отдельное место, а при замене ядра требуется запас под загрузку, распаковку и сохранение предыдущей версии.

Аппаратный тест пройден на KN-3812 (ARM64). Для ARMv7, MIPSEL и MIPS проверены сборки и ELF. Выбрать архив.

Ядро Xray

Выпуск проверен с Xray 26.11.9. Xray загружается отдельно через «Главная → Ядро Xray». Официальные Xray для MIPSEL и MIPS собраны с hardfloat. На устройствах без такой поддержки нужна совместимая сборка ядра. Релиз Xray.

Протоколы и форматы импорта

Поддерживаются ссылки vless://, vmess://, trojan://, ss://, hysteria2:// и hy2://. URL источника подписки должен использовать HTTPS. Приложение принимает список ссылок в обычном тексте или Base64.

Для VLESS проверены комбинации RAW/TCP, WS, gRPC, HTTPUpgrade, XHTTP и mKCP с допустимыми настройками защиты. Linux-проверка Xray подтверждает принятие тестовых конфигураций и отдельный рабочий VLESS-туннель. Конкретный сервер проверяйте после импорта.

Файлы

  • Приложение /opt/broray-light/bin/broray-light.
  • Постоянное состояние /opt/broray-light/state.
  • Служба /opt/etc/init.d/S24broray-light.
  • Временные данные и журнал /tmp/broray-light/run.

Границы редакции

Для Routes, DNS-over-TLS и истории качества используйте полный BROray. Light управляет подключением через три страницы. Приложение и Xray распространяются по собственным лицензиям. История и проверка выпусков.
