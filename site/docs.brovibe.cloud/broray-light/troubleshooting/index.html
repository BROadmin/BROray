Решение проблем BROray-Light

Начните с симптома и запишите сообщение приложения.

WebUI не открывается

В домашней сети проверьте http://LAN-IP:8080/. Если работал только внешний адрес, проверьте в Keenetic статус зарегистрированного KeenDNS или CrazeDNS и имя публикации brolight. Light оставляет чужое правило на месте, если оно уже использует это имя.

В Entware shell проверьте /opt/etc/init.d/S24broray-light status и журнал /tmp/broray-light/run/daemon.log. Ошибка unsafe directory /opt/etc/init.d означает, что нужен доверенный том с подходящим владельцем и правами.

Сервер не подключается

На Главной убедитесь, что установлено ядро Xray. На вкладке «Серверы» откройте параметры нужного профиля и нажмите Проверить. Проверьте часы роутера, рабочий WAN и состояние SOCKS через команду готовности. Возможность разобрать ссылку не гарантирует доступность сервера.

На MIPS и MIPSEL уточните, поддерживает ли роутер hardfloat официального ядра. Совместимость Xray.

Подписка не обновляется

Проверьте, что ссылка доступна по HTTPS и источник отдаёт текст со ссылками или Base64. Повторите вручную и запишите сообщение. При ошибке действующий список сохраняется. Если рабочий ответ больше не содержит активного сервера, Light проверяет замену по порядку. Скройте токен ссылки перед обращением за помощью.

Ошибка обновления

Проверьте дату роутера, доступ к GitHub и сообщение об ошибке. Манифест с ошибочной подписью, истёкшим сроком или неподходящим архивом отклоняется. При незавершённой установке используйте команды проверки и восстановления. Для shell-версий используйте ручной переход.

Данные для диагностики

Укажите модель роутера, архитектуру Entware, версию Light, версию Xray и точное сообщение. Перед восстановлением сохраните /opt/broray-light/state отдельно. Не публикуйте архив состояния, пароли, токены подписок или ключи серверов.
