# JOURNAL-DURABILITY-001

Исправлена подтверждённая потеря диагностики: удаление целой последней JSONL-строки больше не выдаётся за полный журнал. Исходный отказ сохранён в `docs/evidence/journal-tail-reproducer-20260915/` рабочего проекта.

Каждое добавление резервирует монотонный номер в durable `head.json`, затем native guard добавляет одну ограниченную строку и выполняет `fsync` файла и каталога. Завершающая запись watermark содержит последний номер и SHA-256 строки. Неоконченная reservation, пропуск последовательности, потеря сегмента, несовпадение tail hash и повреждение watermark отражаются как неполная/недоступная диагностика. Признак обнаруженной потери сохраняется при последующих добавлениях. Старые сегменты без watermark не принимаются за доказанно полный журнал.

Native guard v5 сохраняет flock-протокол v4; добавлен ограниченный `--append-file` с проверкой типа, прав, числа ссылок, размера и inode назначения. История ограничена прежними тремя сегментами по 262144 байта и последними 500 событиями в ответе. Публичные поля проходят allowlist projection.

## Проверки

- Основной Linux-прогон: 79 PASS за 346,34 с (coordinator, projection, native guard, смерть родителя native writer и reproducer журнала).
- Расширенные проверки: 26 PASS за 87,72 с (8 journal и 18 native guard).
- Изолированный физический Keenetic ARM64: 7 PASS; архив SHA-256 `f811d82030504ea64ac8fd954d68aa33b448bf4a0069954e10866648b06af0ce`. Тестовые namespaces удалены после архивации.
- Локальные syntax/source checks PASS; native ARM64/x86_64 собран дважды с совпадающими байтами.

## Ограничения

Это компонентный checkpoint. Физические self-SIGKILL и искусственная потеря файлов не являются испытанием отключения питания. Полный/readonly носитель, отказ до сохранения reservation, ротация при отключении питания и общая приёмка приложения остаются отдельными проверками. Постоянный Xray/VPN не запускался; релиз не опубликован.
