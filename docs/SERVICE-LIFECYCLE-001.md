# SERVICE-LIFECYCLE-001

S27/S28 теперь сохраняют полную identity daemon, удерживают постоянный kernel lease и принимают запрос остановки для конкретного поколения. PID/starttime служат совместимой проекцией для updater. Статус не удаляет неоднозначные записи; stop не посылает сигналы процессам из PID-файлов. Подтверждённо мёртвое поколение очищается только под lifetime и control guards.

Foreground job закрывает descriptor службы перед exec. Поэтому живой job или постоянный Xray не удерживает lease погибшего scheduler. Дополнительная асинхронная shell-обёртка отклоняется до запуска job.

## Проверки

- Linux: 29 PASS (11 lifecycle, 8 auto-switch, 10 subscriptions), 617,55 с. Полные исходные hashes и лог: `docs/evidence/service-regression-linux-20260915` в корне проекта.
- Роутер: 9 PASS в изолированном namespace, `physical-services-20260915-05`. Архив SHA-256 `a9c7fcaa96cf55cee0396e5ca4db6c1127e01924aa6536fef4ed4a491a4c1499`; namespace удалён после архивации.
- Интерфейс: 14 проверок DOM настоящей страницы servers.html с подставленными HTTP-ответами. Различаются запуск, остановка, подтверждённая остановка и неопределённое состояние. Только два JS-файла изменены после backend-прогонов; их окончательные hashes закреплены отдельным UI-отчётом.
- Сохранены ожидаемые FAIL исходного status, лишней async-обёртки и stale-stop. Попытка physical-03 не используется как доказательство stale-stop: ошибочный AND-list пропускал отказ. Исправленный assertion воспроизвёл дефект в physical-04; исправление прошло physical-05.
- Первый сводный прогон исчерпал RAM файловой системы гостя при копировании fixture. После очистки завершённых service fixtures повторный полный прогон прошёл. Это не испытание продукта на ENOSPC.

Первый UI harness открывал домашнюю страницу вместо servers.html и завершился timeout. Исправлен адрес стенда; production-изменений для этого не требовалось.

Это компонентный checkpoint. S23/S24, остальные producers, protected recovery, полная установка, постоянный VPN, reboot и длительная приёмка остаются открытыми. Релиз не опубликован.
