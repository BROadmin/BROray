# Приёмка BROray 3.5.8

Выпускаются бинарники принятого кандидата 2 без пересборки.

- DNS: целевые тесты normal/race, дополнительные проверки точного удаления normal; код DNS после race не менялся. DoT фильтра не становится собственностью BROray.
- WebUI:69 Node-тестов; ранее проверены 60 сцен 10 страниц ×3 темы ×2 ширины и обработчики кнопок с изолированным API. Это не аппаратное исполнение всех операций.
- Четыре извлечённых архива: фактические preflight/install/start/ping/stop/uninstall в offlineVM; проверка статических ELF и контрольных сумм.
- Три независимых проверки подписи канала. Закрытый ключ не доставлялся на роутер.
- NC-1812/aarch64: штатный подписанный переход 3.5.7→3.5.8, один HTTP202, committed. Обязательный повторный вход выполнен.
- DNS unknown→determinate:0 явных записей и 1 запись встроенного фильтра, runtime сверён, managed0/deletefalse. Apply/Delete не выполнялись.
- Проверены технические сведения DNS, кнопка обновления при уведомлении, раскрытие предупреждения у реального сервера, отсутствие дубля на главной.17 реальных HTML/CSS/JS HTTP200 совпали по SHA-256 с исходниками.
- 38 защищённых файлов, init, основной config, Xray26.11.9 и его конфигурация сохранены.16 серверов и активное подключение сохранены; SOCKS работает, состояние operational/ok. Конфигурационные строки Keenetic совпали; отличается только комментарий Last change. Перезагрузки не было.
- Автоматика возобновлена, активных заданий нет, канал восстановлен. Своё временное содержимое flash удалено; копия восстановления оставлена в RAM.

Общий healthy=false не маскируется: на проверенном устройстве оставалось DNS_APPLY_REQUIRED, поскольку выбраны 5 серверов, а явных записей 0. Настройки DNS не менялись. Это не прежняя ошибка неизвестного состояния.

Первые ошибки оснастки сохранены: сравнение разделителей Windows/POSIX; жёстко заданная старая версия в тесте кеша; начальная ошибка DOM-фикстуры; неверный read-only URL; таймаут ожидания браузера. В конце терминал обрезал хвост длинной команды после очистки; короткая независимая проверка чтением подтвердила результат, удаление не повторялось.

Ограничения: не повторялись неизменённые долгие тесты, разрушительные аппаратные действия, физические испытания других архитектур и новый тест VPN-загрузки. Это приёмка исправлений 3.5.8 с сохранением прежних доказательств и ограничений.
