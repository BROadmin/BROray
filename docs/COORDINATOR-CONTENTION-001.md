# Кратковременная занятость координатора

На установленном r03c01 воспроизведён отказ API остановки при четырёхсекундном удержании существующего kernel flock координатора. Первый запрос вернул 503 STATE_UNAVAILABLE через 2,125 с; повтор после освобождения guard был принят. Тест удерживал только flock и не менял operation state, не удалял locks и не посылал сигналы. Причина более раннего одиночного отказа WebUI не установлена: этот reproducer доказывает механизм, но не происхождение того события.

Клиент теперь повторяет вызов guard только при exit 75 и пустом stdout: этот ответ означает истечение ожидания до запуска координатора. Всего три попытки, примерно шесть секунд ожидания. Структурированный PUBLICATION_UNCONFIRMED с тем же кодом, небезопасный guard и остальные ошибки не повторяются. Kernel guard и native ABI не менялись.

Дополнительно summary подписок использует время подтверждённой terminal попытки, как и карточка. На r03 карточка показывала фактическую отмену, а summary — время предыдущего обновления. Чтение остаётся без записи metadata.

## Проверки

- 48 Linux PASS, 535,86 с: contention (5), subscription jobs (10), supervisor (8), handoff (3), responses (10), HTTP (12). Включены ограниченное ожидание, неизменность fence/state, отсутствие повтора структурированного отказа и lifecycle дочерних процессов.
- 3 physical prefix PASS: transient stop, bounded persistent contention, read-only summary. Namespace заархивирован и удалён; установленное приложение этим прогоном не менялось.
- Проверка исходников, syntax и preserved baseline PASS.

Evidence: `coordinator-contention-001`, `physical-coordinator-contention-20260916`, baseline `full-subscription-r03-20260916/http-stop-contention-baseline.json`.

## Полное приложение r03

Штатное WebUI-обновление r02→r03 завершилось success (`update-20260915224248-17018`). SHA дерева, службы, сеть, доступ и защищённые файлы проверены. DNS с доменным именем исправлен. Обычная отмена через настоящий HTTP API вернула 202 и завершила загрузку как CANCELLED; конкурирующий CLI refresh отклонён, identity постоянного Xray сохранена. Тестовая подписка удалена, файлы восстановлены, временный HTTP источник завершился. VPN-трафик с реальным сервером ещё не проверен.

Это промежуточный checkpoint. Исправления contention/summary требуют следующего кандидата и повтора через установленный HTTP API. Stable не опубликован; ROOT_CAUSE_NOT_PROVEN исходного пользовательского инцидента сохраняется.
