# Полевое подтверждение BROray 2.2.5

Дата: 31 июля 2026 года.

## Публикация

Серверная публикация завершилась успешно:

```text
Состояние: success
Код: 0
Публичный Packages + IPK, обычный и no-cache пути: OK
Старые версии сохранены для автоматического отката: OK
BROray 2.2.5 опубликован: OK
WebUI: WebUI-2.2.0-r3
```

## Исходное состояние роутера

```text
Установленный пакет: broray 2.1.1-2
Приложение: BROray 2.1.1
```

Обновление выполнялось только пользовательским путём:

```text
WebUI → BROray → Проверить обновление → Установить обновление
```

Ручной `opkg install` и локальный IPK не использовались как релизный тест.

## Выявленные дефекты старого updater

До успешной установки полевой тест обнаружил:

1. старый backend трактовал отсутствие `SHA256sum` как несовпадение контрольной суммы;
2. парсер должен читать локальный OPKG-список как в обычном виде, так и в `src/gz`;
3. значение `BRORAY_OPKG_LISTS_DIR=/opt/var/opkg-lists` отсутствовало в скопированном фоновом worker;
4. старая логика создавала резервную копию в `/opt`, уменьшая место для OPKG;
5. перед установкой обязателен порядок: удалить старые автоматические копии и мусор, проверить `/opt` и `/tmp`, создать одну актуальную проверенную копию только в `/tmp`.

## Результат

Пользователь сообщил: **«Установилось»**. Это подтверждает завершение установки 2.2.5 через WebUI после исправления совместимости старого updater.

Эта запись не заменяет отдельную полную функциональную приёмку всех страниц и модулей после установки; она фиксирует именно успешный релизный путь обновления.
