# Расширение импорта BROray — локальная приёмка

Дата: 8 ноября 2026. Основа: опубликованная 3.5.1, commit `b2acc8348dbee4e741f8a4c8f4fcf6ccc39bce9e`. Рабочая ветка: `codex/protocol-import-expansion`. Включает ранее подготовленный импорт AmneziaWG только для хранения. Изменения не опубликованы и не установлены на роутеры.

## Реализовано

- SOCKS5 и HTTP/HTTPS: ссылки, IPv6, логин/пароль с percent encoding, TLS, Xray JSON в плоском и servers/users форматах.
- WireGuard: клиентский INI и Xray JSON, адреса, ключи, несколько пиров, AllowedIPs, MTU, Reserved, DNS, keepalive. Работает через userspace Xray; не создаёт интерфейс ОС. Не выполняет команды INI и не подменяет AWG обычным WireGuard.
- Hysteria2: Xray JSON, сохранение UDP idle timeout и FinalMask.
- WS/HTTPUpgrade: дополнительные заголовки; WS heartbeat. gRPC: пять согласованных дополнительных параметров. Общие выбранные sockopt, включая Shadowsocks и Hysteria2. URI использует JSON-поле `streamOptions`; Xray JSON — родные блоки.
- Неизвестные URI/legacy VMess JSON поля отклоняются с безопасным названием поля. Расширенные поля проходят общую валидацию до preview/save; `false` и `0` сохраняются. XHTTP padding alias нормализуется с проверкой конфликтов. Служебные параметры сопровождаются предупреждениями.
- WebUI принимает новые схемы и один многострочный WireGuard INI. HTTP/HTTPS явно помечены как TCP-only в preview и карточке. AWG остаётся с отключёнными подключением и проверкой качества.
- Приватные WireGuard, streamOptions и FinalMask не выдаются в публичных details. Полная конфигурация остаётся в приватном хранилище и генераторе Xray.

Точные границы схем: [PROTOCOL-SUPPORT.md](PROTOCOL-SUPPORT.md).

## Замечания ревью и исправления

| Важность | Проблема | Исправление и проверка |
|---|---|---|
| P1 | WireGuard JSON превращался в INI с комментарием имени, после чего фильтр подписки удалял весь узел | Комментарии отфильтровываются только в исходных списках ссылок; JSON→extract→stage RED/GREEN |
| P2 | SS сохранял sockopt, но Outbound не выдавал streamSettings | Условная выдача streamSettings, сохранение прежних байтов без расширений; RED/GREEN и настоящий UDP |
| P2 | XHTTP alias изменял запись после базовой валидации; preview мог принять запись, которая затем падала на save | Полная валидация итоговой записи до возврата из ParseLink; RED/GREEN для `0-1` |
| P2 | Пароль HY2 FinalMask попадал в публичные details | Маскирование FinalMask; JSON→stage→MaskRecord RED/GREEN с отдельной проверкой сохранности приватного Outbound |

Повторный просмотр этих четырёх исправлений не выявил оставшихся проблем. Ревью не заменяет тесты; результаты прогонов приведены отдельно.

## Первые неудачи сохранены

- Предусмотренные RED для отсутствовавших импортёров, потерянных параметров, UI-ограничений и четырёх ошибок ревью находятся в `protocol-*-red*` и истории инструментов.
- Первые WG тесты использовали скалярное сравнение для массива Reserved; исправлена проверка массива. Один тест HTTP-заголовка использовал form-encoding `+` вместо URI `%20`; оснастка исправлена. Тест WebUI сначала подставлял короткий canonical вместо обязательных 64 hex; это ошибка оснастки.
- Первый реальный HTTPS прогон обнаружил неверный ALPN тестового сервера: объявлялся h2, хотя inbound обслуживал HTTP/1.1. WireGuard handshake проходил, но обращение к 127.0.0.1 шло в loopback его userspace-стека. Тестовый сервер теперь объявляет HTTP/1.1; WG проверяется через виртуальный адрес назначения с локальным перенаправлением на эхо-сервис. Первые логи: `protocol-core-first`, `protocol-core-diagnostic`; подтверждение исправления: `protocol-core-fixture-corrected`.
- Дополнительный SS-тест сначала добавил query через `&` к ссылке без `?`. Исправлен только построитель тестовой ссылки; первый результат `protocol-ss-options-traffic`, подтверждение `protocol-ss-options-green`.
- Старые тесты ожидали отсутствия SOCKS/HTTP и отклонения всех sockopt. Обновлены только изменившиеся ожидания; прочие 3.x fixture-сравнения остаются. `extra=0` вне XHTTP теперь явно отклоняется как неприменяемый параметр.
- Ошибки редактирования/компиляции оснастки (кодировка Python, тип переменной error, замена строкового `net`) разобраны до запуска соответствующих прогонов. Они не записаны как продуктовый PASS.

## Границы результата

Полная матрица всех комбинаций протоколов, транспортов и параметров не заявляется. Runtime проверен на ARM64 VM с одним официальным Xray; для других архитектур выполнена сборка. Нового аппаратного прогона, race-проверки всей системы и повторения старых циклов установки/удаления не было. Не менялись маршрутизаторы, подписки пользователей, производственные ключи и опубликованные архивы.

Отложены MASQUE/XDRIVE, TUIC/MTProto/SSR/Snell, подключение AWG, изменение идентичности SNI/ShortID и политика исчезнувшего активного сервера. Они не включены скрытно в этот пакет.

Git commit не создан: ранее подтверждено отсутствие author identity. Чужое имя/email не подставлялись, глобальная конфигурация Git не менялась. Рабочее дерево сохранено; локальный снимок исходников и хеши доступны в `G:\GPT-Codex\BROray-3.5.1\artifacts\protocol-import\`.

Итог: локальный пакет согласованного расширения реализован и проверен в указанном объёме. Следующий этап — подготовка отдельного кандидата и его приёмка перед публикацией.
