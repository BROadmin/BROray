# BROray 3.5.4

Stable · 11 ноября 2026. Установочные архивы совпадают с принятым кандидатом.

BROray продолжает развитие знакомого менеджера Xray для Keenetic. В версии 3.5.4 улучшено обслуживание ядра на устройствах с небольшим свободным хранилищем. Архитектура Go, интерфейс и пользовательские данные сохраняются.

## Что нового

- Архив Xray загружается в оперативную память вместо /opt. Перед распаковкой проверяются официальная контрольная сумма и выбранный файл для архитектуры роутера.
- Обычная установка сохраняет старое ядро в /opt до проверки нового. Нужны место под новый бинарник и резерв; архив больше не занимает постоянное хранилище.
- Режим нехватки места сохраняет старый Xray в RAM и освобождает его место перед распаковкой нового. Режим включается отдельно и требует подтверждения. При отключении питания копия в RAM пропадёт; автоматический откат в этом случае не гарантируется.
- Кнопка «Удалить Xray» удаляет только ядро. Серверы, подписки, настройки и маршруты остаются. WebUI доступен, автоматическая переустановка отключена до явной установки выбранной версии.
- Журнал обслуживания помогает отличить завершённую установку от прерванной. Автовыбор не пытается подключать серверы при намеренно удалённом ядре; его настройки сохраняются.
- Проверяются доступная RAM и фактическая RAM-файловая система, место /opt и точный размер ядра из проверенного архива. До изменения установленного файла выполняется повторная проверка ресурсов.

## Как пользоваться

Откройте **Xray → Проверить версии**. Выберите нужную версию и нажмите **Установить** или **Переустановить**. По умолчанию используется обычный режим с постоянной копией для отката.

Если /opt мало, включите **«Режим нехватки места: резервная копия ядра в RAM»**, прочитайте предупреждение и подтвердите установку. На время замены VPN будет недоступен. Не отключайте питание роутера.

Для отдельного удаления нажмите **«Удалить Xray»**. После этого на той же странице проверьте список версий и установите прежнюю или другую подходящую версию. Данные BROray повторно вводить не нужно.

## Обновление и ограничения

С 3.5.x обновляйтесь через страницу BROray. Xray обновляется отдельно; обновление BROray само по себе не меняет выбранное ядро. С 3.2 требуется чистая установка по инструкции сайта. После перезапуска BROray потребуется повторный вход; перезагрузка роутера не нужна.

RAM не заменяет постоянное хранилище: установленный бинарник остаётся в /opt. Оставляется минимум 32 MiB оперативной памяти и 8 MiB /opt; ресурсы, занятые другими службами, также влияют на возможность установки. При неподтверждённом RAM-хранилище или нехватке ресурсов установка отклоняется.

Ограничения 3.5.3 сохраняются: WireGuard не прошёл запуск в эмуляции MIPS/MIPS LE; аппаратный результат неизвестен. Реальные Google Drive/WARP без выделенных реквизитов не проверены. AmneziaWG разбирается и хранится без запуска; TUIC/MTProto не добавлены. Новый переключатель UDP в этот выпуск не входит. Непроверенные аппаратные сценарии не считаются успешно пройденными.
