# BROray 3.5.9

Stable · 20 ноября 2026.

## Ревизия r3

«Безопасная очистка» объединяет одинаковые GeoIP и GeoSite с сохранением истории отката. При обновлениях BROray повторно использует одинаковые файлы. Очистка удаляет распознанные устаревшие версии и проверенные старые копии перед импортом. WebUI показывает изменение свободного места после операции.

## Что нового

- Готовые и свои доменные списки видны в Keenetic вместе с правилами маршрутизации.
- Резервирование VPN использует основной сервер и до двух запасных. При отказе всего состава BROray временно переходит на автовыбор и возвращается после восстановления.
- Исправлено удаление серверов подписки. На странице «Серверы» можно удалить все сохранённые серверы, кроме активного.
- Добавлены блокировки для трафика через BROray, импорт IPv6-маршрутов, IPv6 DNS-over-TLS с проверкой доступности и настройки обхода DPI для совместимых профилей.

## Обновление через WebUI

Обновление на BROray 3.5.9 выполняется через WebUI установленной версии 3.5.0–3.5.8. Обновитель скачивает сборку для вашего роутера из подписанного канала Stable.

1. Откройте действующий WebUI и перейдите на страницу **BROray**.
2. Скачайте резервную копию настроек.
3. Нажмите **Проверить обновление**. Убедитесь, что предлагается версия **3.5.9**.
4. Нажмите **Установить обновление**. Дождитесь завершения и войдите снова. Убедитесь, что на странице **BROray** указана версия **3.5.9**.

Если уже установлена **3.5.9**, скачайте резервную копию. На странице **BROray** нажмите **Проверить обновление**, затем **Переустановить**. После завершения войдите снова. В исправленной сборке команда удаления подписки отправляется в штатную очередь.

Встроенное обновление доступно для ветки 3.5. Переход с 3.2 через WebUI не поддерживается.
