# ASSERTION-AUDIT-001

В 54 составных assertions физических shell-тестов добавлен явный отказ. Исходное `[ false ] && [ true ]` могло пропускаться под `set -e`, после чего сценарий записывал PASS. Минимальное воспроизведение и исходные скрипты сохранены отдельно; завершённые checkpoints не изменялись.

Повторены все затронутые наборы на физическом ARM64: supervisor 10, handoff 9, launch 17, guard/writer 5, subscriptions 10, servers 9, auto-switch 7, Xray fixtures 7, journal 7 и core/lifecycle 28. Итого **109 PASS**. Каждый отдельный namespace архивирован и удалён после успешного завершения. SHA-256 архивов и точных входных файлов находятся в `checkpoints/BROray-3.1.1-ASSERTION-AUDIT-001.json` в корне проекта.

Core/lifecycle materialized в отдельный текущий harness для ABI guard v5. Старые deploy/cleanup runners не запускались. Общий runner также проверяет каждый путь отдельной командой до архивации и удаления.

Это повтор компонентных проверок с исправленным стендом. Полное приложение, постоянный VPN и длительная совместная работа ещё не проверены. Релиз не опубликован.
