# Приёмка BROray 3.5.6

12 ноября 2026. Бинарники четырёх архитектур совпадают с кандидатом 1. Изменения документации не требуют пересборки.

На KN-1811/aarch64: подписанное обновление 3.5.5 → 3.5.6 завершилось committed. Временная подписка разобрала 18 записей URI/JSON/Clash, сохранила 16 уникальных, отклонений 0. Новый экземпляр в отдельном RAM-каталоге с пустой конфигурацией автоматически создал внешний адрес; экран входа ответил HTTP 200 без настроенного сервера VPN. Проверенный Xray был предварительно скопирован, повторная загрузка ядра не выполнялась. Рабочая установка и подключение восстановлены.

На NC-1812/aarch64: штатное подписанное обновление 3.5.5 → 3.5.6, повторный вход и обновление существующей проблемной подписки завершены. Число записей и отказов подтверждено отдельной аппаратной квитанцией; настройки и состояние VPN сохранены. Полного удаления, перезагрузок и изменений чужих объектов не было.

Локально: сохранены RED, целевые проверки установщика normal/race, Keenetic Web API и импортера Hysteria2 normal/race прошли. Для импортера по 8 верхнеуровневых тестов и 63 подтеста в каждом успешном прогоне. Четыре извлечённых CLI lifecycle и три проверки подписи PASS; исходники и архивы связаны SHA-256. Независимая проверка кода не выявила P1/P2. Неизменённые протокольные и длительные проверки не повторялись.

Ограничения: реальное железо только aarch64; свежая установка проверялась в изолированном RAM-каталоге, а не после полного удаления данных. Трафик всех импортированных узлов не проверялся. На первом роутере отложенная оснастка восстановления не запустилась из-за отсутствия nohup; восстановление выполнено через независимый root webshell. Первый код 1 восстановления был вызван служебной строкой Last change, отдельная проверка настроек прошла. Полная побайтная неизменность всех серверных файлов не заявляется: после проверки зафиксировано отдельное ручное обновление существующей подписки. Первые ошибки оснастки сохранены, а не переименованы в PASS.

Итог NC-1812: 18 получено, 18 разобрано, 16 уникальных, 0 отклонений.

На NC-1812 команда ndmc для снимка running-config вернула system failed до и после обновления. Эти ответы не использованы как доказательство полного совпадения конфигурации Keenetic. Побайтно проверены файлы настроек BROray до обновления подписки и основной конфиг после него; внешний адрес имеет enabled/consistent без recovery.
