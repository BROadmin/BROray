# Установка BROray 3.5

**Требуется чистая установка BROray 3.5. Обновление поверх BROray 3.2 не поддерживается.**

Для перехода необходимо штатно удалить предыдущую версию BROray, затем установить новую 3.5 на Keenetic с Entware. Существующий канал обновлений 3.2 этой установкой не переключается.

Для первой установки, начиная с BROray 3.5.10, скопируйте обе строки из блока на странице выбранного выпуска и вставьте их в терминал Entware. Команда проверяет контрольную сумму скрипта, определяет архитектуру Entware и проверяет контрольную сумму выбранного архива перед установкой. После запуска установщик сообщает версию и доступный адрес WebUI.

Для ручной установки выберите архив под архитектуру роутера (aarch64, armv7, mipsel или mips) и сверьте SHA-256 с контрольными суммами выпуска.

BROray 3.5.10 отправляет подтверждение первой установки и успешных обновлений в фоновом режиме, если в сборке настроен приёмник статистики. В событие входят тип операции, версия, ревизия и архитектура. При наличии данных роутера добавляются код модели и постоянный ключ для подсчёта уникальных устройств. BROray вычисляет его на роутере из серийного номера. Сам серийный номер, адреса, настройки и содержимое трафика в событие не входят.

Последующие обновления самой ветки 3.5 используют отдельный подписанный канал:

`https://api.brovibe.cloud/releases/broray/channels/stable/manifest.json`

Публичный ключ выпуска 3.5 имеет ID `16FE8A3DA9ED98DC` и встроен в сборку. Закрытый ключ не включается в исходники, архивы или установку на роутере.
