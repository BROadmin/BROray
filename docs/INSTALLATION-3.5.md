# Установка BROray 3.5

**Требуется чистая установка BROray 3.5. Обновление поверх BROray 3.2 не поддерживается.**

Для перехода необходимо штатно удалить предыдущую версию BROray, затем установить новую 3.5 на Keenetic с Entware. Существующий канал обновлений 3.2 этой установкой не переключается.

Выберите архив под архитектуру роутера: aarch64, armv7, mipsel или mips. До установки сверьте SHA-256 архива с контрольными суммами выбранного выпуска. Окончательные ссылки и команды установки публикуются вместе с проверенным выпуском; внутренний кандидат dev13 ещё не является опубликованным релизом.

Последующие обновления самой ветки 3.5 используют отдельный подписанный канал:

`https://api.brovibe.cloud/releases/broray/channels/stable/manifest.json`

Публичный ключ выпуска 3.5 имеет ID `16FE8A3DA9ED98DC` и встроен в сборку. Закрытый ключ не включается в исходники, архивы или установку на роутере.
