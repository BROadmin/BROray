# WebUI BROray


Повседневная работа с BROray 3.5.7: знакомые страницы, состояния и действия.


<a id="login"></a>
## Вход и навигация


Откройте локальный адрес роутера с портом 8080 и войдите учётной записью администратора Keenetic. Это не логин root от Entware. После перезапуска или обновления BROray нужно войти заново. Темы переключаются в шапке.


| Страница | Для чего нужна |
| --- | --- |
| Главная | Общее состояние Xray, подключения, подписок, DNS, маршрутов и интерфейса. Предупреждение в одной карточке не означает отказ остальных модулей. |
| Серверы | Импорт, выбор активного подключения, проверка качества и настройка автовыбора. |
| Подписки | Добавление ссылки, обновление, расписание и просмотр узлов провайдера. |
| DNS-over-TLS | Выбор и проверка DNS, применение, внешние записи и автопроверка. |
| Маршруты → Обзор | Сводка наборов и фактических записей в Keenetic. |
| Маршруты → Свои маршруты | Предпросмотр BAT, собственные наборы и изменение записей. |
| Маршруты → Готовые маршруты | Каталог из 12 сервисов, скачивание, установка и проверка обновлений. |
| Keenetic | Состояние ProxyN, upstream, описание интерфейса и доступ через KeenDNS. |
| Xray | Запуск, остановка, диагностика, конфигурация и официальные версии ядра. |
| BROray | Версия приложения, обновление, переустановка, восстановление, копии и очистка. |


Для входа через внешний адрес сначала [включите публикацию KeenDNS](https://docs.brovibe.cloud/broray/start/#remote-webui). В инструкции также описаны [веб-терминал](https://docs.brovibe.cloud/broray/start/#web-terminal) и [обновление старой страницы в браузере](https://docs.brovibe.cloud/broray/troubleshooting/#stale-cache).


<a id="servers"></a>
## Серверы и качество


1. Добавьте ссылку или выберите узел подписки.
2. Активируйте нужный сервер.
3. Нажмите «Проверить» у активного подключения. Дождитесь результата проверки соединения и обновления качества.
4. Для резерва раскройте настройки автоматического переключения и выберите правило.


Ручная проверка активного сервера сохраняет качество. Неудачное дополнительное измерение не превращает успешное подключение в неисправное. Одинаковый сервер, добавленный вручную и из подписки, может отображаться отдельными записями разных источников.


На странице «Серверы» можно вставить ссылку, клиентский WireGuard/AmneziaWG INI, Xray JSON или Clash/Mihomo YAML/JSON; JSON/YAML также можно выбрать как UTF-8 файл. Ручной документ должен давать ровно один клиентский узел. Документ с несколькими серверами добавляйте через подписку: BROray не выбирает первый узел молча. HTTP/HTTPS-адрес в поле сервера означает прокси; URL подписки указывайте на странице «Подписки». Перед сохранением проверьте результат и предупреждения.

<a id="subscriptions"></a>
## Подписки


Подписка принимает списки ссылок, одну Base64-оболочку над поддержанным документом, Xray JSON (отдельные outbound, полные профили и допустимые массивы), Clash/Mihomo YAML/JSON, клиентский WireGuard INI и поддержанные клиентские контейнеры Amnezia. Полный профиль не заменяет настройки BROray: DNS, маршруты, rules, группы прокси и локальная политика остаются под управлением приложения.

Начиная с 3.5.2 смена SNI/Short ID сохраняет ID одного узла при однозначном соответствии. Совпадающие по прочим параметрам старые варианты внутри одной подписки объединяются; ручные записи и другие подписки остаются отдельными. Если узел удалён провайдером, полный успешно разобранный ответ удалит его из BROray. Для исчезнувшего активного узла VPN отключается; включённый автовыбор ищет замену по своим настройкам. Если подходящей замены нет, поиск повторяется после защитного интервала. При выключенном автовыборе выберите сервер вручную. Ручное отключение VPN отменяет поиск.

Пустой, повреждённый или частично разобранный ответ не подтверждает удаление прежних узлов. Прочитайте предупреждения. Валидный AmneziaWG в режиме «Только сохранение» сам по себе не означает ошибку подписки.

[Форматы и ограничения импорта](https://github.com/BROadmin/BROray/blob/main/docs/PROTOCOL-SUPPORT.md).


<a id="routes"></a>
## Маршруты


Сначала скачайте и проверьте набор, затем установите его в Keenetic. Панель операции показывает ход работы и доступные действия остановки и продолжения. Не отправляйте повторно ту же установку, пока не выяснен статус первой. Для своих BAT доступен предпросмотр: файл разбирается как данные, не запускается как сценарий.


Наборы: ChatGPT, Claude, Facebook, Instagram, Meta, Netflix, Speedtest, Telegram, TikTok, WhatsApp, Wikipedia и YouTube. Источник IP-адресов может менять их количество; число записей не является постоянной характеристикой выпуска.


<a id="dns"></a>
## DNS-over-TLS


Отметьте нужные DNS, проверьте их доступность и прогноз применения. Внешние записи показаны отдельно; применение выбранных серверов не даёт BROray права владения чужими записями. При сообщении о восстановлении сначала выполните предлагаемый сценарий, затем повторно проверьте состояние.


<a id="keenetic-xray"></a>
## Keenetic и Xray


Страница Keenetic показывает управляемый интерфейс и состояние внешнего доступа. Действия восстановления и синхронизации видны, когда для них есть основание. Не нужно добиваться их появления на исправном интерфейсе. На странице Xray сначала проверьте обновления; статус совместимости относится к конкретной версии и архитектуре. Предварительная или непроверенная версия требует подтверждения.


<a id="operations"></a>
## BROray и фоновые операции


Обновление приложения и обновление Xray — разные действия. В разделе BROray доступны копия, её предпросмотр и импорт, а также отмена импорта из сохранённого предыдущего состояния. Журнал и панель операций помогают понять, идёт ли задание, завершено ли оно и можно ли его продолжить. [Обслуживание по шагам](https://docs.brovibe.cloud/broray/maintenance/).


## Xray 26.11.9 и импорт

Для XDRIVE/MASQUE требуется Xray 26.11.9. Обновите ядро отдельно на странице «Xray»; установка BROray не заменяет его автоматически. При несовместимом ядре сохранение профиля допустимо, но подключение, качество и автовыбор блокируются с объяснением. Поле support-x25519mlkem768 — метаданные Mihomo, оно не передаётся как параметр Xray; обмен определяется поддержанным TLS-профилем и сервером.

Подключение через KeenDNS возвращает номер фоновой операции. Следите за результатом; не отправляйте запрос повторно при задержке. [Ограничения и приёмка](ACCEPTANCE-3.5.7.md).


### Дополнительные форматы и предупреждения

В настройках каждой подписки есть независимые переключатели «Дополнительно загружать JSON» и «Дополнительно загружать Clash». Оба по умолчанию выключены, в том числе у прежних подписок без этих настроек. Включите нужные форматы до обновления, если хотите получать явно объявленные дополнительные выгрузки того же источника. Прямая ссылка на JSON или Clash работает независимо от этих переключателей.

Сохранение переключателей не меняет список сразу. При следующем полном успешном обновлении записи только из отключённого дополнительного формата могут быть удалены из этой подписки; ручные записи сохраняются. Ошибка получения или разбора включённой дополнительной выгрузки сохраняет прежний список. Если основная ссылка возвращает только HTML, включите нужный дополнительный формат либо укажите прямую ссылку на конфигурацию. JavaScript не выполняется; пути не угадываются, вложенные providers не загружаются.

При необходимости включите «Дополнительно загружать JSON» и/или «Дополнительно загружать Clash» и сохраните подписку. Затем нажмите «Обновить». По умолчанию дополнительные выгрузки не запрашиваются.

«Предупреждения обновления» на странице «Подписки» раскрываются по нажатию. Предупреждения сохранённого сервера доступны в его карточке и разделе «Подробнее». Предупреждение о сохранённых, но неприменяемых метаданных отличается от запрета подключения: ориентируйтесь на результат импорта и сообщение карточки. Валидная приватная запись без возможности подключения сама по себе не означает повреждённую подписку.

Если версия Xray не определена, сначала проверьте состояние ядра; это не доказательство необходимости обновления. Отсутствие ответа STUN означает, что UDP в этой проверке не подтверждён, а не установленную причину отказа сервера.
