# BROray 3.2.0-r02 — автоматика, подписки и восстановление

**Stable · 1 октября 2026 года.**

Предыдущий выпуск 3.2.0-r01 отозван из-за дефектов. Предыдущий действующий Stable — 3.1.1-r12. Новый r02 заменяет его; отозванный r01 остаётся отозванным.

## Что изменилось относительно 3.1.1

- **Приоритеты фоновых операций.** Проверка активного соединения получает преимущество; длительные задания выполняются короткими этапами. Исправлены пауза и возобновление автоматики, обновление результатов проверок и статус активного подключения.
- **Подписки без потери узлов.** Исправлены BOM и пробелы, дедупликация по параметрам подключения и сохранение ID при однозначной смене реквизитов. Исчезнувшие серверы удаляются после полного успешного обновления; при частичном ответе сохраняются с предупреждением.
- **Больше поддерживаемых конфигураций.** Расширены VLESS, VMess, Trojan, Hysteria2 и JSON-импорт Shadowsocks. Добавлены современные VMess URI, Vision-udp443, mKCP, поддерживаемые TLS/REALITY, XHTTP и FinalMask-параметры. Существующие варианты SIP002/AEAD-2022 сохранены.
- **Надёжнее обновление и запуск.** Исправлены повторный запуск updater, восстановление после перезагрузки, блокировки старой миграции и запуск служб/WebUI. Ожидания завершения служб согласованы с их фактическим состоянием.
- **Установка и удаление.** LAN-адрес определяется по конфигурации Keenetic с выбором при неоднозначности. Полное удаление может продолжить незавершённые шаги; Entware и чужие настройки сохраняются. Маршруты удаляет Keenetic при удалении принадлежащего BROray интерфейса.
- **Маршруты и DNS-over-TLS.** Исправлены установка готовых маршрутов, обновление их статусов, создание интерфейса после удаления и автопроверка DoT. Устаревшее подтверждение удаления DoT отклоняется без изменений.
- **Совместимость Xray.** Результаты сохраняются между кандидатами при неизменных проверенных компонентах. Частично совместимую версию можно установить после подтверждения ограничений. Добавлены данные для 26.9.30.
- **Подготовка Xray в RAM.** Загрузка и проверка выполняются в оперативной памяти; доступное место проверяется до остановки рабочего ядра.
- **WebUI.** На Главной появилась отдельная карточка DoT; исправлены версия приложения, статусы, мобильная вёрстка и сообщения об ошибках. Журнал и история фоновых операций раскрываются по запросу.
- **Обслуживание хранилища.** Исключена неиспользуемая графика; обычные логи ротируются, завершённая история обслуживается по безопасным правилам. Защищённые сведения восстановления не удаляются ради квоты.

## Исправления после отозванного r01

- Закрыты воспроизводимые сбои старого migration/preflight, восстановления остановленного updater и запуска WebUI через штатную ссылку службы.
- Исправлены команды системного CLI Keenetic и ожидание готовности/завершения служб, включая повторный сбой Xray restart.
- Каталог маршрутов получает свежую сводку после изменений вместо повторного использования старого ответа.
- Исправлен отказ проверки происхождения запросов KeenDNS при медленном чтении большой конфигурации.
- Проверка обновления дожидается информации об установке и не показывает ложное неполное состояние.
- Новая revision r02 распознаётся как обновление относительно r01.

## Что проверено

Функциональный код принят на KN-2710 Peak / KeeneticOS5.1.4 / ARM64 в кандидате c46: чистая установка, полное удаление, обновления 3.0.0-r14c68 и 3.1.1-r12c01, переустановка, десять страниц WebUI, совместная автоматика и прогон 7259,08 с с тремя перезагрузками. Обновление 3.1.1 проверено с 1101 маршрутом.

После изменения revision на r02 выполнены две побайтно совпадающие сборки и отдельное обновление тестового r01c46 → r02c01 через WebUI. Все 372 файла и права сверены; настройки и 1108 маршрутов сохранены; проверены десять страниц и отображение совместимости Xray. Функциональный код совпадает с c46, изменены генерируемые идентификаторы и метаданные. Полный двухчасовой прогон r02 повторно не выполнялся.

## Ограничения

- Поддерживаемая сборка: ARM64 / Entware aarch64-3.10. KeeneticOS5.2 отложена до отдельной приёмки.
- Совместимость Xray означает результат проверенных конфигураций и сценариев BROray. Для 26.9.30 выполнены 41/41 проверок конфигураций на ARM64; реальные подключения через эту версию отдельно не подтверждены.
- Внешние SIP003-плагины Shadowsocks и произвольные полные профили Xray не поддерживаются. Все возможные сочетания параметров не объявляются проверенными.
- При обновлении приложения Xray может штатно перезапускаться; бесшовность VPN не обещается.
- Переход со старого updater может потребовать штатной перезагрузки и повторения команды установщика. Внезапное отключение питания не испытывалось.
- Обработка снимков 3500/10000 маршрутов проверена целевыми утилитами; физическая установка 10000 маршрутов не заявляется.

## Установка и обновление

[Проверяемая команда установки](https://docs.brovibe.cloud/broray/start/). Переход со старых версий, начиная с 3.0.0, выполняйте этим установщиком. Если он сообщает `REBOOT_REQUIRED=YES`, перезагрузите Keenetic через его интерфейс и повторите ту же команду. Итог успешного выполнения — `BRORAY_INSTALL=PASS`. Пользовательские данные и установленный бинарный Xray сохраняются; служба может штатно перезапускаться.
