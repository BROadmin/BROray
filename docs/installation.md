# Установка и обслуживание BROray 3.0.1

## Перед началом

Убедитесь, что роутер соответствует [требованиям](requirements.md). Все команды ниже выполняются в Entware shell от `root`. Для обычного обновления уже установленной ветки 3.0.0 не запускайте `opkg update`: универсальный updater использует установленные зависимости и подписанный HTTPS-канал напрямую.

Проверить наличие нужных инструментов можно без изменения системы:

```sh
command -v curl
command -v jq
command -v mktemp
command -v sha256sum
command -v awk
command -v sh
```

## Обновление любой установленной версии 3.0.0

Для обычного обновления используйте WebUI:

```text
BROray → Проверить обновление → Установить обновление
```

Текущий Stable поддерживает единый переход с любой исправной версии, начиная с `3.0.0-r1`. Кандидат и версия OPKG не выбирают отдельный сценарий: сравниваются только установленный и текущий подписанный `releaseId`.

- установленная версия старее — обновление;
- версии равны — успешное завершение без изменений;
- установленная версия новее — отказ от понижения без изменений.

Если WebUI недоступен, загрузите универсальный Stable-установщик, проверьте его SHA-256 и запустите:

```sh
(
set -eu
PATH=/opt/broray/bin:/opt/sbin:/opt/bin:/opt/usr/bin:/opt/usr/sbin:/usr/sbin:/usr/bin:/sbin:/bin
export PATH
for cmd in curl jq mktemp sha256sum awk sh rm; do command -v "$cmd" >/dev/null; done

T="$(mktemp /tmp/broray-stable-update.XXXXXX)"
trap 'rm -f "$T"' EXIT

curl -q \
  --proto '=https' \
  --proto-redir '=https' \
  --tlsv1.2 \
  --connect-timeout 15 \
  --max-time 600 \
  --retry 3 \
  -fsSL \
  -H 'Cache-Control: no-cache, no-store' \
  -H 'Accept-Encoding: identity' \
  'https://api.brovibe.cloud/releases/stable/broray/3.0.1-r05/INSTALL-ON-ROUTER.sh' \
  -o "$T"

[ "$(sha256sum "$T" | awk 'NR==1{print $1}')" = \
  '53665e09bd7f14fd9e2764d2f55f0db649bc47995e2fee17cdd88304bd8af226' ]

sh "$T"
)
```

Для уже актуального Stable ожидается:

```text
UPDATE_DECISION=already-current
INSTALLED_RELEASE=3.0.1-r05
CURRENT_RELEASE=3.0.1-r05
RELEASE_MUTATION=NONE
ENVIRONMENT_RECONCILED=YES
```

## Установка с нуля

Текущий универсальный Stable-установщик обслуживает и обновление, и чистую установку. При первой установке он проверяет состояние Entware, получает подписанный release index и сразу разворачивает целевое приложение `3.0.1-r05c01`. Пакет OPKG `3.0.0-r14` используется только как регистрационный и lifecycle-якорь: приложение `r14c68` не устанавливается и не запускается, updater-v5 не выполняет внутренний переход.

Если BROray на роутере ещё не установлен:

1. Откройте терминал Entware на роутере.
2. Войдите как `root`.
3. Один раз выполните команду установки необходимых пакетов:

```sh
opkg update &&
opkg install ca-bundle ca-certificates curl jq
```

Если BROray уже установлен и вы его обновляете, пропустите этот шаг.

```sh
(
set -eu
PATH=/opt/broray/bin:/opt/sbin:/opt/bin:/opt/usr/bin:/opt/usr/sbin:/usr/sbin:/usr/bin:/sbin:/bin
export PATH
for cmd in curl jq mktemp sha256sum awk sh rm; do command -v "$cmd" >/dev/null; done
T="$(mktemp /tmp/broray-clean-current.XXXXXX)"
trap 'rm -f "$T"' EXIT
curl -q --proto '=https' --proto-redir '=https' --tlsv1.2 \
  --connect-timeout 15 --max-time 600 --retry 3 -fsSL \
  -H 'Cache-Control: no-cache, no-store' -H 'Accept-Encoding: identity' \
  'https://api.brovibe.cloud/releases/stable/broray/3.0.1-r05/INSTALL-ON-ROUTER.sh' \
  -o "$T"
[ "$(sha256sum "$T" | awk 'NR==1{print $1}')" = \
  '53665e09bd7f14fd9e2764d2f55f0db649bc47995e2fee17cdd88304bd8af226' ]
sh "$T"
)
```

Успешная чистая установка содержит `UPDATE_DECISION=clean-install`, `CLEAN_BOOTSTRAP=PASS`, `INTERMEDIATE_APPLICATION_RELEASE=NONE` и завершается строками `BRORAY_INSTALL=PASS`, `CANDIDATE=3.0.1-r05c01`, `STABLE=YES`. Частично установленное или неоднозначное состояние отклоняется без обхода защитных проверок.

## Альтернативная установка через штатный механизм Keenetic

Отдельный подписанный bootstrap позволяет поставить проверенную базовую версию `r14c68` через каталог `/opt/install/*.tgz`. Это альтернативный вариант, когда архив удобнее перенести на накопитель роутера через SFTP или USB, а запуск выполнить штатной перезагрузкой Keenetic. В отличие от обычной терминальной установки, после загрузки этого отдельного архива требуется обновление через WebUI до текущего Stable `3.0.1-r05`.

Bootstrap не меняет Stable-канал, updater-v5 или байты `r14c68`. Перед любым сетевым запросом он проверяет встроенную подпись и затем принимает только закреплённые SHA-256 Stable-объектов.

Кратко:

1. Скачайте архив, подпись, публичный ключ и проверочный скрипт.
2. На доверенном компьютере проверьте SHA-256, fingerprint ключа и внешнюю подпись.
3. Скопируйте только принятый архив в `/opt/install/`.
4. Перезагрузите роутер штатной командой KeeneticOS или через WebUI.
5. После загрузки проверьте статус bootstrap и BROray.

Полная инструкция, прямые ссылки и команды проверки: [установка подписанного bootstrap через Keenetic](keenetic-web-cli-install.md).

## Вход в WebUI

Прямой вход по LAN-адресу:

```text
http://<LAN-IP-роутера>:8080/
```

LAN-адрес определяется при установке.

Если на роутере настроен KeenDNS, установщик создаёт для BROray отдельный HTTP Proxy с поддоменом `broray`. Адрес формируется так:

```text
http://broray.<KeenDNS-домен-роутера>/
```

Для домена роутера `myrouter.keenetic.link` это будет:

```text
https://broray.myrouter.keenetic.link/
```

Указывать порт `8080` в KeenDNS-адресе не нужно. Запрос по HTTP автоматически перенаправляется на HTTPS. Возможность входа только из домашней сети или также через Интернет определяется режимом KeenDNS и настройками доступа роутера.

Авторизуйтесь учётной записью Keenetic; не публикуйте пароль и данные сессии в Issue.

## Проверка установки

```sh
/opt/broray/bin/broray-system info
/opt/bin/broray-updaterctl version
/opt/bin/broray-updaterctl check
/opt/etc/init.d/S22broray-updater status
```

Для текущего релиза ожидаются release `3.0.1-r05`, кандидат `3.0.1-r05c01`, WebUI `WebUI-3.0.1-r05c01`, пакет OPKG `3.0.0-r14`, `broray-updater/5`, канал `stable` и отсутствие доступного обновления.

Прямая чистая установка и отсутствие промежуточного приложения подтверждены для архитектуры текущего Stable. Для `r05c01` физически проверены WebUI-обновление, все обязательные службы, Xray, семь серверов, автоматическое обновление подписки, три DNS-over-TLS-записи, 12 маршрутов Wikipedia, KeenDNS и все страницы WebUI. Повторный запуск публичного Stable-установщика завершился без мутации. Универсальный переход от `3.0.0-r1` и updater-v5 не изменялись.

## Обычное обновление

В WebUI откройте:

```text
BROray → Проверить обновление → Установить обновление
```

Операция получает отдельный идентификатор, проверяет Stable index и архивы, готовит новый app-slot и переключает его только после preflight. После переключения проверяются версия, OPKG-регистрация, backend WebUI, Xray и ранее работавшие службы. Ошибка после переключения запускает откат к предыдущему app-slot.

После завершения обновления обязательно очистите кэш браузера и заново откройте WebUI. На компьютере обновите страницу сочетанием `Ctrl+R`; на мобильном устройстве очистите кэш сайта в настройках браузера и перезагрузите страницу.

## Переустановка текущей версии

На странице **BROray** выберите переустановку. Updater-v5 использует текущий кандидат и тот же транзакционный путь, что и обновление. Пользовательское состояние и общий Xray runtime не входят в сменяемый app-slot.

Переустановка запускается только отдельной кнопкой или явным запросом `reinstall`. Повторный запуск универсальной Stable-команды при равном release завершится без изменений.

## Аварийное административное обновление

Если WebUI не открывается, но Entware shell доступен, выполните проверяемую Stable-команду из раздела «Обновление любой установленной версии 3.0.0». Она обновляет только более старый release, ничего не меняет при равном и отказывается понижать более новый.

Если updater-v5 и приложение исправны, но требуется только отправить административный запрос на доступное обновление:

```sh
/opt/bin/broray-updaterctl check &&
/opt/bin/broray-updaterctl request update
```

Состояние операции:

```sh
/opt/bin/broray-updaterctl status
```

Для переустановки уже текущего кандидата:

```sh
/opt/bin/broray-updaterctl request reinstall
```

Не удаляйте lock-файлы вручную и не запускайте новую операцию, пока предыдущая имеет состояние `running` или `recovery-required`.

## Что сохраняется

При штатном обновлении или переустановке сохраняются:

- сохранённые серверы и активный выбор;
- подписки;
- пользовательские маршруты и их исходные файлы;
- управляемые receipts и чужие маршруты Keenetic;
- выбранные и установленные DNS-over-TLS записи;
- управляемый интерфейс Keenetic;
- общий Xray runtime и рабочая конфигурация.

## Переход с 2.x

Встроенного обновления `2.x → 3.0.0` нет. Сохраните нужные данные, выполните штатное удаление 2.x и установите 3.0.0 с нуля. Не используйте `opkg upgrade broray` поверх старой ветки.

## Если проверка остановилась

Остановка до мутации обычно означает несовместимую архитектуру, отсутствие компонента, недостаток места, конфликтующую операцию или неоднозначную старую установку. Скопируйте только обезличенный текст ошибки и обратитесь в [поддержку](../README.md#поддержка). Не публикуйте подписки, UUID, ключи и полные конфигурации.
