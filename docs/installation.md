# Установка BROray 3.5.10 — по шагам

Выберите свою модель, откройте Entware через браузер или SSH, скопируйте готовую команду и войдите в WebUI BROray.

## Если уже установлена версия 3.5

Откройте [инструкцию по обновлению и переустановке через WebUI](update.md).

## Выберите свой случай

- **Уже установлена версия 3.5:** откройте [инструкцию по обновлению](update.md).
- **BROray ещё не установлен:** начните с [подготовки роутера](#prepare).
- **Установлена 3.2:** сначала выполните раздел ниже, затем чистую установку. Не начинайте с установочной команды поверх старой версии.

<a id="prepare"></a>
## 1. Подготовьте роутер


1. Убедитесь, что интернет и основная панель роутера работают. Проще выполнять установку из домашней сети. Если доступен только внешний адрес KeenDNS, используйте веб-терминал в шаге 2.
2. Найдите номер модели **KN-xxxx** или **NC-xxxx** на наклейке либо в системном мониторе. У разных поколений одного названия архитектура может отличаться.
3. Проверьте компоненты `proxy` и `opkg`. Для внешнего адреса или DNS-over-TLS выберите соответствующие дополнительные компоненты из таблицы.
4. Нужен установленный **Entware** и не менее **60 МиБ** свободного места в `/opt`. Если встроенного хранилища недостаточно, Entware размещают на подходящем USB-накопителе.
5. Если Entware ещё нет, сначала установите его по [инструкции производителя](https://support.keenetic.com/hero/kn-1012/en/20980-installing-the-entware-repository-on-a-usb-drive.html). Если Entware уже работает, повторно устанавливать его не нужно.


<a id="keeneticos-components"></a>
### Компоненты KeeneticOS перед установкой

**До установки Entware и BROray установите необходимые компоненты KeeneticOS.** В основной панели роутера откройте «Управление» → «Настройки системы» → «Изменить набор компонентов» (в некоторых версиях — «Общие настройки» → «Обновления и компоненты»). Найдите и отметьте отсутствующие компоненты:

| Код или название для поиска | Компонент | Для чего нужен |
| --- | --- | --- |
| `proxy` | Клиент прокси (Proxy client) | Создание управляемого интерфейса ProxyN и подключение к SOCKS5 Xray. |
| `opkg` | Поддержка открытых пакетов (Open Package support) | Работа Entware, в котором устанавливается BROray. |
| `ndns` | KeenDNS / CrazeDNS | Интеграция с доменным именем роутера и публикация WebUI через KeenDNS. |
| DNS-over-TLS | Прокси-сервер DNS-over-TLS (DNS-over-TLS proxy) | Работа раздела DNS-over-TLS в BROray: применение выбранных DNS-серверов с шифрованием запросов. |

В списке компонентов ищите «Прокси-сервер DNS-over-TLS» (DNS-over-TLS proxy). Это отдельный компонент для DNS-over-TLS; KeenDNS / CrazeDNS (`ndns`) его не заменяет.

Примените изменения и дождитесь возвращения панели роутера. Изменение набора компонентов может обновить KeeneticOS и вызвать перезагрузку с временным разрывом доступа. Уже установленные компоненты повторно устанавливать не нужно.

Если Entware расположен на USB-накопителе с ext4, дополнительно нужна поддержка файловой системы Ext. Компонент «Интерфейс командной строки в браузере» нужен только для варианта установки через веб-терминал.

Ошибка `unsupported interface type: "Proxy"` при создании интерфейса означает, что текущая прошивка не предоставляет тип Proxy. Проверьте установку `proxy`; изменение названия сервера эту ошибку не устраняет. Если нужного компонента нет в списке, проверьте поддержку для своей модели и версии KeeneticOS до продолжения установки.

Go на роутере не нужен. Для установки 3.5 используйте блоки этого руководства.


<a id="ssh"></a>
## 2. Откройте терминал Entware


Достаточно одного из двух вариантов ниже. Дальнейшие команды установки выполняются в shell Entware со строкой, заканчивающейся символом `#`.


<a id="web-terminal"></a>
### Вариант А. Веб-терминал в браузере


> **Компоненты и перезагрузка** Изменение набора компонентов может одновременно обновить прошивку и автоматически перезагрузить роутер. Мастер покажет предлагаемую версию и запросит подтверждение. Подтверждайте этот шаг, когда готовы к временному разрыву доступа; затем дождитесь возвращения панели. Сама установка BROray ниже перезагрузки не требует.


1. Войдите в основную панель Keenetic или Netcraze учётной записью администратора. Можно использовать её рабочий адрес KeenDNS.
2. Откройте «Управление» → «Настройки системы» → «Изменить набор компонентов». Найдите **«Интерфейс командной строки в браузере»**. Если компонент уже установлен, повторно устанавливать его не нужно.
3. Если компонента нет, отметьте только его и прочитайте итоговый список изменений перед подтверждением.
4. На странице «Менеджер пакетов OPKG» включите **«Доступ»** напротив своей учётной записи администратора, например admin, и сохраните. Entware и его накопитель должны быть уже настроены.
5. Нажмите шестерёнку в верхней части панели → **«Интерфейс командной строки»**. Пункт «Консоль RCI» — другой инструмент.
6. Если появилась строка `(config)>`, введите следующую команду один раз:


```sh
exec sh
```


Должна открыться BusyBox/ash и строка с `#`. Теперь можно вставлять команды BROray. Если `exec sh` возвращает в `(config)>`, проверьте доступ OPKG для своей учётной записи и готовность Entware; установочные команды пока не вводите.


<a id="ssh-entware"></a>
### Вариант Б. SSH из домашней сети


1. В Termius или PuTTY создайте SSH-подключение к локальному IP-адресу роутера, например `192.168.1.1`.
2. Для SSH Entware укажите пользователя **root** и пароль Entware. Это другие данные, чем вход администратора в основную панель.
3. Обычно Entware использует порт **222**, если порт 22 занят встроенным SSH роутера. Иначе может использоваться **22**. Используйте порт, указанный при настройке Entware.
4. Нужна строка shell с `#`. Если вы вошли во встроенный CLI и видите `(config)>`, переход в Entware выполняется командой `exec sh` при включённом доступе OPKG, как в варианте А.


> **Если есть только облачный адрес** Открывающаяся по KeenDNS панель не означает, что через этот адрес доступен SSH. Для такого случая используйте веб-терминал. Логин root и пароль Entware не вводятся в форму WebUI BROray.


> **Как вставлять команды** Копируйте блок целиком кнопкой «Скопировать», вставляйте в терминал и нажимайте Enter. Дождитесь результата и возврата строки с `#`. В SSH при вводе пароля символы обычно не отображаются — это нормально.


<a id="download-tools"></a>
## 3. Подготовьте загрузку по HTTPS


Если curl уже установлен и загрузки HTTPS работают, этот шаг можно пропустить. Иначе один раз выполните блок для установки curl и сертификатов:


```sh
opkg update && opkg install ca-bundle ca-certificates curl
```


Если opkg завершился ошибкой или не найден, сначала исправьте Entware либо подключение к нему; к следующему шагу пока не переходите.

## 4. Установите BROray 3.5.10

Выполните обе строки в одном сеансе Entware с правами root. Первая задаёт Stable и GitHub. Вторая скачивает скрипт, проверяет его SHA-256 и запускает. Установщик определяет архитектуру и проверяет SHA-256 архива. При сбое загрузки или несовпадении хеша со Stable команда пробует GitHub.

```sh
export BRORAY_REPOS='https://api.brovibe.cloud/releases/broray/channels/stable https://github.com/BROadmin/BROray/releases/download/v3.5.10'
(set -f; f=$(mktemp /tmp/broray.XXXXXX) || exit; trap 'rm -f "$f"' 0; for u in $BRORAY_REPOS; do curl -q -fsSL --proto '=https' --proto-redir '=https' --connect-timeout 8 -m 25 -o "$f" -- "$u/install-broray-3.5.10-r15.sh" && echo "af6a88b07e6a4ca673ba2b49f8c5fb4e9b37639063cbd43555d39bbff231c5f7  $f" | sha256sum -c - && { /opt/bin/ash "$f"; exit $?; }; done; echo 'Нет установщика с верным SHA-256.' >&2; exit 1)
```

Проверить архитектуру можно командой `opkg print-architecture`. Поддерживаются ARM64, ARMv7, MIPS и MIPSEL. [Сборки и модели](https://docs.brovibe.cloud/broray/reference/#architectures).

## 5. Дождитесь результата


Не закрывайте терминал, пока идёт установка. При успехе установщик выводит `BROray 3.5.10`. Для дополнительной проверки запустите `/opt/bin/broray ctl ping`. Команда установки не перезагружает роутер. Xray скачивается при первом запуске; дождитесь окончания загрузки по статусу в WebUI.


| Что вы видите | Что делать |
| --- | --- |
| `INSTALL_SPACE_REQUIRED` | Обеспечить 60 МиБ свободного места на накопителе Entware. Не обходить проверку. |
| `INSTALL_LEGACY_PRESENT` | Завершить штатное удаление прежнего BROray. При ошибке старого удалителя остановиться и разобрать причину. |
| `INSTALL_ARCH_MISMATCH` или `Exec format error` | Сверить номер модели и результат `opkg print-architecture`. |
| Ошибка curl / сертификата / SHA-256 | Не продолжать вручную. Проверить интернет, время и сертификаты; сохранить ошибку для поддержки. |
| `opkg: not found` или `(config)>` | Проверить доступ к Entware и переход `exec sh` по шагу 2. |


<a id="open-webui"></a>
## 6. Откройте WebUI BROray


<a id="local-webui"></a>
### Из домашней сети


Откройте **http://IP-адрес-роутера:8080/**. Например, для панели на `192.168.1.1` это **http://192.168.1.1:8080/**. Если локальный вход уже работает, внешний адрес при необходимости можно включить на странице «Keenetic».


<a id="remote-webui"></a>
### Если доступен только KeenDNS


При чистой установке адрес broray.… создаётся автоматически, если настроен KeenDNS. Если установщик сообщил предупреждение или адрес ранее был отключён, включите его вручную. Оставьте основную панель роутера открытой и в уже работающем терминале Entware выполните команду **3.5**:


```sh
/opt/bin/broray ctl post /api/keenetic/web-access-enable.cgi '{}'
```


Дождитесь ответа `success:true`, затем посмотрите адрес и состояние публикации:


```sh
/opt/bin/broray ctl get /api/keenetic/web-access-status.cgi
```


В ответе найдите `data.address` и откройте этот адрес в браузере. При успешном включении `data.state` — `enabled`, а `data.enabled` и `data.consistent` — `true`. Домен роутера подставляется программой. При ошибке остановитесь и разберите её по коду; [проверка внешнего адреса](https://docs.brovibe.cloud/broray/troubleshooting/#keendns-only).


<a id="first-login"></a>
### Вход и первое подключение

> **KeeneticOS 5.2: NDW4.** Для входа через новый механизм авторизации KeeneticOS 5.2 нужен пароль администратора длиной не менее 8 символов. Измените пароль в разделе “Пользователи и доступ” веб-интерфейса роутера, сохраните изменения и повторите вход в BROray.

Это требование нового механизма NDW4, а не общее ограничение всех старых версий KeeneticOS и авторизации NDW2. [В Keenetic войти получается, а в BROray — нет: порядок действий и ошибки 502/503](authentication-faq.md#keeneticos-52-short-password).


1. Введите имя и пароль **администратора Keenetic или Netcraze**. Здесь нужны данные основной панели роутера, а не root и пароль Entware.
2. Если открылась старая страница 3.2, выполните принудительное обновление **Ctrl+F5**; в Firefox также доступно **Ctrl+Shift+R**. Затем на странице «BROray» проверьте версию 3.5.10 и ревизию r15. При необходимости откройте адрес в новой приватной вкладке.
3. Откройте **Быстрая настройка**. Добавьте ключ сервера или ссылку на подписку и проверьте подключение. [Как пройти мастер](RELEASE-3.5.10.md#быстрая-настройка).
4. Нажмите «Проверить» у активного сервера. Затем установите нужные наборы на странице «Маршруты → Готовые маршруты». Выбор трафика устройств определяется маршрутами и политиками роутера.


После чистой установки список серверов пуст. Xray может быть установлен, но остановлен до выбора сервера и создания его конфигурации; это ожидаемое состояние. Данные 3.2 автоматически не переносятся. После перезапуска или обновления BROray потребуется повторный вход.
