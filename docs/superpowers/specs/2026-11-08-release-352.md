# BROray 3.5.2: синхронизация подписок и расширенный импорт

Основание: прямое поручение владельца от 2026-11-08. Это продолжение BROray; основа — опубликованная 3.5.1 и уже проверенные локальные изменения импорта.

## Поведение

- Полный ключ конфигурации сохраняет SNI/ShortID. Ключ преемственности узла внутри одной подписки не зависит от SNI/ShortID.
- При единственном новом варианте узла старые записи, различающиеся только SNI/ShortID, объединяются. Учётные данные, протокол, endpoint, транспорт и прочие параметры остаются значимыми. Сохраняется активный ID, иначе точное совпадение, иначе стабильный прежний ID.
- Несколько разных текущих вариантов и неоднозначная ротация учётных данных не объединяются произвольно. Ручные записи и другие подписки не затрагиваются.
- Полный достоверный ответ удаляет отсутствующие узлы. Повреждённый/пустой/частично неразобранный ответ сохраняет прежние несопоставленные записи; распознанный AWG теперь является сохранённым узлом, а не ошибкой разбора.
- Исчезновение активного узла больше не отменяет синхронизацию всей подписки. Владелец выбрал: при включённом автовыборе искать замену по его настройкам; иначе отключить VPN. Настройки автовыбора сохраняются. При отсутствии кандидата повторять по защитному интервалу, с явным статусом.
- Все изменения каталога и подключения проверяются на отказ и откат. WebUI должен оставаться доступным при отказе VPN.

## Выпуск

Версия 3.5.2, четыре архитектуры aarch64/armv7/mipsel/mips. Включает уже проверенный импорт SOCKS/HTTP(S)/WireGuard/Hysteria2 JSON и расширений транспортов; AWG — только хранение, MASQUE/XDRIVE не входят.

Сначала локальная проверка изменённого кода и независимое ревью, затем сборки/подпись/офлайн-переход и тестовый KN-1811. После аппаратной приёмки подготовить публикацию и понятные документы с историей версий. Обновление 3.5.1 поддерживается; переход с 3.2 требует чистой установки.

Запрещены перезагрузка, полное удаление, изменения чужих объектов и запись секретов в отчёт. Ранее принятые тесты не повторяются без затрагивающих изменений. Публикация не выполняется этим подготовительным этапом.
