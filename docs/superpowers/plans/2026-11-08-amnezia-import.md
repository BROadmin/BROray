# План импорта AmneziaWG

Основание: ../specs/2026-11-08-amnezia-import-design.md. Выполнение в текущей сессии, самостоятельно по поручению владельца.

1. RED/GREEN: независимый internal/amnezia.ParseLink(string) (Imported, error). Проверить qCompress/Base64URL, структуру AWG и INI, сохранение расширений, лимит распаковки, повреждения, неоднозначные контейнеры. Ошибки не содержат исходные данные.
2. RED/GREEN: areas/servers ParseLink/Validate/CanonicalKey/ContinuityKey/MaskRecord. Отдельная модель amneziawg, поддержка чтения/записи/backup. XrayConfig и API отказывают до запуска процессов. qualitySnapshot исключает неподдерживаемые узлы.
3. RED/GREEN: areas/subscriptions распознаёт vpn://, принимает валидный AWG с предупреждением. Проверить смешанную и только AWG подписки, ротацию и удаление; повреждённый узел остаётся rejected.
4. RED/GREEN: servers.js отображает статус и блокирует подключение/проверку/выбор AWG. Проверить настоящие функции JS на синтетическом DOM, затем существующие JS-регрессии.
5. Проверить пакеты servers/subscriptions в Linux VM и независимый парсер на хосте, diff/сборку; записать фактические результаты и ограничения, без изменения опубликованного выпуска.

## Особые случаи проверки

- Размер в qCompress не совпадает с результатом; распаковка превышает предел.
- Несколько контейнеров, пустой/неизвестный vpn:// и ложная подпись AWG.
- Секрет в last_config, неизвестном поле и nativeConfig: в публичном API не виден.
- Поддерживаемые серверы должны проверяться даже при наличии AWG.
- Валидный AWG не включает retain-unmatched, повреждённый контейнер включает.
