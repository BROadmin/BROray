# BROray 3.5.5

BROray продолжает развивать существующий менеджер Xray для Keenetic. Версия 3.5.5 посвящена импорту подписок. Stable · 11 ноября 2026. Установочные архивы совпадают с принятым кандидатом 4.

## Исправления

- Пустой строковый диапазон XMUX принимается как нулевой, как в Xray. Это устраняет отказ части VLESS/XHTTP-ссылок и JSON-профилей.
- Корректный `level` в Xray JSON больше не служит причиной отказа сервера. BROray явно предупреждает, что использует собственные локальные политики: `level` не является реквизитом доступа к VPN-серверу. Это относится и к XDRIVE.
- При отказе всех узлов подписки сохраняются счётчики и причины отказа. Ранее WebUI мог показывать нули и общее сообщение, хотя содержимое было получено и разобрано.
- Если в JSON XDRIVE отсутствует обязательный клиентский `mux`, BROray добавляет `mux.enabled=true` с явным предупреждением. Указанные пользователем некорректные значения по-прежнему отклоняются; настройки и реквизиты транспорта сохраняются.
- На странице «Серверы» варианты одного подключения из разных подписок объединяются в карточку с выбором источника. Различия SNI, Short ID и поддержанных клиентских параметров XHTTP не создают дополнительные карточки. Учётные данные, адрес и значимые параметры транспорта учитываются при группировке; все исходные записи сохраняются независимо.
- Раскрытый список серверов подписки обновляется после изменения её содержимого, включая замену узла без изменения общего количества. Возвращение на вкладку обновляет сведения, полученные в другом окне.

## Импорт Clash

Добавляется импорт серверов из Clash/Mihomo YAML по ссылке подписки. Переносится список серверов; правила, группы прокси, DNS и другие настройки клиента Clash не меняют настройки Keenetic или BROray. Неподдерживаемые параметры и протоколы получают явные причины отказа.

Параметр XHTTP `no-grpc-header` переносится в `noGRPCHeader` Xray с сохранением значения `true` или `false`.

Поддержаны VLESS, VMess, Trojan, Shadowsocks, HTTP, SOCKS5, базовые Hysteria2 и WireGuard, а также сохранение AmneziaWG без подключения. Для потоковых протоколов предусмотрены TCP, WS, gRPC, XHTTP и HTTPUpgrade в допустимых сочетаниях. [Точная матрица и ограничения](PROTOCOL-SUPPORT.md#clashmihomo-по-ссылке-подписки) перечислены отдельно: поддержка формата не означает поддержку любой опции Mihomo.

## Одна ссылка — несколько форматов

Версия 3.5.5 добавляет автоматическое обнаружение JSON и Clash на странице основной подписки. BROray запрашивает её HTML-представление и использует явно указанные ссылки на выгрузки того же сайта. Поддерживаются ссылки с обозначением формата и данные страницы 3x-ui `subJsonUrl` / `subClashUrl`; адреса выгрузок не угадываются.

Полученные конфигурации входят в одну подписку. Полностью совпадающие подключения сохраняются один раз; различающиеся реквизиты, транспортные настройки и расширения не отбрасываются. Варианты одного подключения по-прежнему могут отображаться одной карточкой с выбором источника. Не нужно создавать отдельную подписку для каждого формата; ранее созданные отдельные подписки автоматически не удаляются.

Если найденная выгрузка не загрузилась или не разобралась, обновление не заменяет прежний список серверов неполным. Ссылки на сторонние сайты, рекурсивные providers Clash и исполнение JavaScript страницы не поддерживаются. Прямые ссылки на JSON, Clash и обычные списки URI сохраняют поддержку.

## Обновление и ограничения

Для ветки 3.5.x предусмотрено штатное обновление с сохранением настроек. После перезапуска потребуется повторный вход. Для BROray 3.2 требуется чистая установка; автоматического переноса с 3.2 нет. BROray начиная с 3.5.0 написан на Go.

Импорт AmneziaWG сохраняет конфигурацию, но не добавляет её исполнение ядром Xray. TUIC и MTProto не становятся поддерживаемыми протоколами благодаря YAML-импорту. Работа WireGuard на настоящих MIPS/MIPS LE не подтверждена; публичный WARP не проверен с выделенными внешними учётными данными. Для XDRIVE Google Drive на KN-1811 успешно загружены файлы 1 и 8 МиБ через изолированный Xray; отмечена высокая задержка. Это не проверка длительной нагрузки или пути LAN через ProxyN. Проверка импорта конкретной подписки не означает проверку трафика всех её серверов.

Возможности управления местом при установке Xray из 3.5.4 сохраняются. RAM-копия ядра в режиме экономии места исчезает при отключении питания.

## Обновление и проверка

С 3.5.0–3.5.4: сохраните копию настроек, откройте BROray → Проверить обновление → Установить обновление. Дождитесь завершения и войдите снова. Пользовательские данные сохраняются, Xray обновляется отдельно. С 3.2 требуется чистая установка по пошаговой инструкции. Go на роутер устанавливать не нужно.
