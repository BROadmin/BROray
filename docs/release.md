# Выпуск BROray 3.1.1

Исходное дерево приложения — `runtime/`. Каталог `root/` и прежние OPKG-сценарии относятся к историческим выпускам и не являются источником 3.1.1.

- Публичный релиз: `3.1.1-r12`, кандидат: `3.1.1-r12c01`.
- Приложение: commit `1d1ab348448857d59165f39dae8c535e64363b80`.
- Установщик revision 3: commit `d05791906fed68bc59fab171ac15c8914406b4ec`.
- OPKG-якорь: `3.0.0-r14`; неизменённый `broray-updater/5`.
- [Заметки и физическая приёмка](RELEASE-3.1.1.md).

Публикация переносит точные принятые байты приложения и bootstrap. Индекс Stable подписан Minisign. Универсальный `INSTALL-ON-ROUTER.sh` получает актуальный подписанный индекс и после закреплённого bootstrap сохраняет канал Stable. Сам bootstrap обращается к неизменяемым, проверенным SHA-256 зависимостям; их нельзя удалять как временные тестовые файлы.

`STABLE-PROMOTION-PROOF.json` в релизе фиксирует происхождение и зависимости; `SHA256SUMS` — контрольные суммы. Изменение кода или installer payload требует новой приёмки. Доказательства локальных тестов не заменяют испытания на физическом роутере.
