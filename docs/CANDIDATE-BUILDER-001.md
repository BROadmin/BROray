# Воспроизводимая сборка приложения: предварительная проверка

Локальный `tools/build_runtime_candidate.py` в корне проекта собирает только `implementation/runtime/`. Он не устанавливает приложение, не подписывает и не публикует файлы. Версии, идентификаторы WebUI и seed version заменяются в копии; исходный проверенный архив 3.1.0 не меняется. Xray остаётся отдельным общим runtime.

Две сборки development candidate `3.1.1-r01c01` дали одинаковые байты: SHA-256 `f03d5e8f86f12307711154b3601cec72188420fdc648d2e36f6f72b191b0c847`, 2 063 894 байта. Сборки выполнены из рабочего дерева с незакоммиченными изменениями и не являются финальными кандидатами. Состав, контрольные суммы, права и нормализованные времена проверяются самим сборщиком.

На физическом Keenetic выполнены четыре проверки архивного слота штатными функциями updater-v5: корректный slot/версии/размеры, ash syntax, отказ при повреждённом файле, отказ при лишнем файле. Доказательства: `docs/evidence/physical-bundle-admission-20260915` в корне проекта; архив SHA-256 `ea5ecf736da93800f471640fbeec5ed87f47ee756c5863deb3cdde8c8da7441f`, 4 841 769 байт. Изолированные каталоги удалены после архивации.

В проверке наличия общего runtime использовался тестовый executable, который не запускался как Xray. Настоящая установка, Xray configuration test, VPN, подписание и публикация этим этапом не подтверждены.
