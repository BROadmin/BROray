# BROray 3.0.1-r01 — Stable

- Публичный release: **3.0.1-r01**
- Пакет OPKG: **3.0.0-r14**
- Технический кандидат: **3.0.1-r01c03**
- WebUI: **WebUI-3.0.1-r01c03**
- Обновитель: **broray-updater/5**
- Архитектура: **aarch64-3.10**
- Дата публикации: **7 сентября 2026 года**

`r01c03` опубликован в Stable из тех же application-байтов, которые прошли локальную, терминальную, пользовательскую WebUI и визуальную проверку. При продвижении кандидат не пересобирался. Updater platform, clean bootstrap и OPKG-якорь не менялись.

Один версионный `INSTALL-ON-ROUTER.sh` обслуживает оба пользовательских сценария. На пустом совместимом Entware он автоматически выполняет проверенный bootstrap `r14c68` и продолжает до `3.0.1-r01`; на установленной ветке `3.0.0-r1` и новее применяет универсальный алгоритм обновления. Документация чистой установки исправлена без изменения Stable-артефактов.

Универсальный алгоритм обновления сохранён: для любой исправной установки от `3.0.0-r1` сравниваются только установленный и текущий подписанный `releaseId`. Более старая версия обновляется, равная завершается без замены приложения, более новая не понижается.

## Исправлено

- Монитор соединения автоматически восстанавливается после неожиданной остановки.
- Устаревший PID и PID постороннего процесса не принимаются за работающий монитор; посторонний процесс не завершается.
- Состояние соединения публикуется атомарно, поэтому пустой, оборванный или некорректный `connection-status.json` не становится авторитетным.
- Завершённая ручная или плановая пакетная проверка серверов публикует единый итоговый снимок для Главной. Промежуточный снимок больше не оставляет ложное предупреждение об устаревшем качестве.
- Неудачная, но завершённая проверка сервера остаётся свежим результатом «недоступен», а не ошибочно помечается как устаревшая.
- Сообщения Главной явно указывают, что счётчик выбранных серверов относится к DNS-over-TLS.

## Добавлено

- Десятый готовый маршрутный набор Wikipedia. Исходный BAT загружается и разбирается как недоверенные данные, никогда не выполняется как команда.
- Полноширинная раскрывающаяся карточка «Доступ к WebUI через KeenDNS» на странице Keenetic.
- Для управляемого адреса `https://broray.<KeenDNS-домен>/` доступны просмотр состояния, включение, отключение, открытие и копирование.
- Операции с адресом используют существующую проверку владения, не перезаписывают чужой HTTP Proxy и не меняют регистрацию или режим KeenDNS роутера.

## Обязательное действие после обновления

После обновления очистите кэш браузера и заново откройте WebUI. На компьютере выполните жёсткое обновление страницы сочетанием `Ctrl+F5`; на мобильном устройстве очистите кэш сайта в настройках браузера и перезагрузите страницу. Это исключает показ HTML старой версии из локального кэша браузера.
