# BROray 3.1.0 — выбор версии Xray

Стабильный релиз **3.1.0-r09** от **10 сентября 2026 года**. Точная сборка: `3.1.0-r09c02`, WebUI: `WebUI-3.1.0-r09c02`.

## Что добавлено

- На странице **Xray** можно выбрать конкретную официальную версию ядра, установить её или переустановить текущую.
- В списке показываются две последние стабильные версии. Переключатель «Показать предварительные версии» добавляет до пяти последних предварительных. Установленная и последняя проверенная совместимая версия остаются доступны без дублирования.
- Для версий отображается один из трёх статусов: **«Совместима с BROray»**, **«Не проверялась на совместимость с BROray»**, **«Несовместима с BROray»**. Оценка относится к текущей сборке BROray, без привязки к модели роутера.
- При чистой установке BROray 3.1.0 автоматически устанавливается **Xray 26.9.9**.

## Что исправлено

- Определение работающего Xray больше не принимает процесс проверки конфигурации за основной процесс и не показывает ложную остановку во время параллельных проверок.
- Исправлена загрузка вспомогательных функций проверки SOCKS при реальной замене ядра.
- Исправлен фильтр предварительных версий: отметка совместимости не раскрывает все предварительные релизы при выключенном переключателе.
- Из карточки выбора удалены повторяющиеся статусы и лишние технические пояснения.

## Совместимость и защита

Для этой сборки в реестре отмечены совместимыми Xray **26.3.27, 26.6.27, 26.7.11, 26.7.28, 26.9.8 и 26.9.9**. Проверка выполнена для публикуемой архитектуры arm64 с конфигурацией VLESS/XHTTP/REALITY. Это не утверждение о проверке всех протоколов и конфигураций.

**Xray 26.2.6 отмечена как несовместимая; её установка через BROray заблокирована.** Подтверждение предупреждений не отменяет этот запрет.

Установка непроверенной или предварительной версии, а также понижение требуют явного подтверждения. До замены проверяются источник, размер, SHA-256, свободное место и конфигурация; после запуска проверяется SOCKS. При неудачной замене предусмотрен возврат прежнего ядра. Эти проверки не ослаблены.

## Установка и обновление

**Обновление BROray не меняет установленную версию Xray.** После обновления при необходимости откройте **Xray → Проверить версии**, выберите 26.9.9 и подтвердите установку. Если она уже установлена, повторная установка не нужна.

Для обновления приложения: **BROray → Проверить обновление → Установить обновление**. Если WebUI недоступен, используйте проверяемую терминальную команду из инструкции:

- [Полная инструкция](installation.md)
- [Пошаговая инструкция для начинающих](beginner-installation.md)
- [Инструкция на сайте](https://docs.brovibe.cloud/broray/)

Чистая установка сразу разворачивает целевой BROray без промежуточной версии приложения. OPKG `3.0.0-r14` остаётся регистрационным якорем, updater-v5 не изменён. После установки с нуля добавьте подписку или сервер и активируйте подключение: сам по себе работающий процесс Xray ещё не означает настроенный VPN.

После обновления очистите кэш браузера и обновите страницу (`Ctrl+R` на компьютере); на телефоне очистите кэш сайта и откройте WebUI заново.

## Проверки

- 49 автоматических регрессионных сценариев, 3 сценария фильтра и 13 групп WebUI-проверок.
- Шесть разрешённых версий прошли физическую матрицу: 281 параллельная проверка конфигурации, 18 из 18 HTTPS-проверок успешны. Ложных остановок и выбора валидатора вместо рабочего процесса не зафиксировано.
- На конечном `r09c02` выполнена настоящая чистая установка через HTTPS, автоматически установлен Xray 26.9.9; проверены вход в WebUI, каталог, запрет 26.2.6, запуск, остановка, перезапуск, диагностика и состояние установки.
- Функциональный код и WebUI конечной сборки побайтово соответствуют испытанному `r09c01` после нормализации идентификаторов; отличие `r09c02` — закреплённое ядро для чистой установки.
- Диагностика чистой установки: 9 успешных проверок, 1 предупреждение об отсутствии прежней записи «Испытание на Keenetic», 0 ошибок. Эта старая запись не является реестром совместимости Xray.
- Переустановка самого Entware, перезагрузка роутера и все возможные протоколы этим испытанием не покрыты.
