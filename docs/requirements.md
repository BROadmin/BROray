# Требования и совместимость BROray 3.0.0

## Поддерживаемая платформа

BROray 3.0.0 допускает установку только после проверки фактических возможностей роутера.

Обязательны:

1. Keenetic с `arch: aarch64` и непустым аппаратным идентификатором.
2. Entware/OPKG с включённой архитектурой `aarch64-3.10`.
3. Open Package, настроенный ровно на одном накопителе и смонтированный как доступный для записи `/opt`.
4. Компоненты Keenetic:
   - `proxy` — Proxy client;
   - `opkg` — Open Package support;
   - `ndns` — KeenDNS/DNS-over-TLS API.
5. Доступные read-only API `show version`, `show ndns`, `show ip http proxy` и `show running-config`.
6. Root-shell Entware, `/opt/bin/ash`, BusyBox, `curl`, `jq`, `ndmc` и рабочий HTTPS.

Установщик проверяет эти условия до постоянных изменений и прекращает работу при неоднозначном ответе.

## Место и временные ресурсы

Для чистой установки применяются фиксированные нижние границы:

| Ресурс | Обязательный минимум | Рекомендация |
| --- | ---: | ---: |
| Свободно на `/opt` | 64 МиБ (67 108 864 байта) | от 100 МиБ |
| Свободно в `/tmp` | 75 МиБ (78 643 200 байт) | от 128 МиБ |
| Временные inode | фактическое создание 4096 файлов | запас сверх минимума |

Для последующих обновлений и переустановок updater-v5 вычисляет требуемое место по фактическим размерам архива и app-slot. Xray использует отдельный динамический расчёт; прежнее фиксированное требование 102 МиБ больше не применяется.

## Зависимости пакета

OPKG-пакет объявляет:

```text
ca-bundle
ca-certificates
curl
findutils
jq
lighttpd
lighttpd-mod-cgi
openssl-util
tar
```

Перед запуском Stable-команды на чистом Entware должны быть доступны как минимум `curl`, `jq` и корневые сертификаты. Остальные зависимости разрешаются OPKG во время установки.

## Проверенная конфигурация

Финальный кандидат физически проверен на Keenetic `KN-2710`, KeeneticOS `5.1.4`, BusyBox `1.37.0` и Entware `aarch64-3.10`.

Это не список из одного поддерживаемого устройства. BROray не запоминает fingerprint, серийный номер или конкретный роутер: новый экземпляр допускается по тем же capability-gates.

## Совместимость версий

- Чистая установка BROray 3.0.0 поддерживается на совместимом незанятом окружении.
- Обновление поддерживается с исправной установки 3.x, содержащей updater-v5 и проходящей проверку целостности.
- Повторная установка текущего Stable выполняется как `reinstall` через updater-v5.
- Прямое обновление с BROray 2.x не поддерживается.
- Прямые `opkg upgrade`, `opkg --force-reinstall`, ручная подмена app-slot и ручное редактирование OPKG-регистрации не поддерживаются.

Перед переходом с 2.x сохраните нужные конфигурации и пользовательские данные, завершите штатное удаление старой ветки и только затем запускайте чистую установку. Если осталось повреждённое или неоднозначное состояние, установщик остановится; не обходите эту проверку и обратитесь в поддержку.

## Сетевые условия

- DNS и системное время должны позволять проверить TLS-сертификаты.
- Должен быть доступен `https://api.brovibe.cloud/`.
- WebUI слушает локальный адрес роутера на порту `8080`.
- Публикация через KeenDNS HTTP Proxy выполняется только в области, которой управляет BROray; чужая настройка не перезаписывается.
