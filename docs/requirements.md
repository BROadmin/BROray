# Справочник BROray 3.5.4


Требования, архитектуры, версии компонентов и важные особенности выпуска.


<a id="requirements"></a>
## Требования


- Keenetic или Netcraze с работающим Entware и подходящей архитектурой.
- Рабочий /opt и не менее 60 МиБ свободного места перед установкой.
- Root-доступ к Entware для установки и администратор Keenetic для WebUI.
- Интернет, корректное время и HTTPS-доступ к GitHub и источникам каталогов.
- Возможности ProxyN и KeenDNS в установленной прошивке: наличие UDP проверяется отдельно.


<a id="go"></a>
## Что изменил переход на Go


Начиная с 3.5.0 основная реализация BROray написана на Go. Исполняемый файл содержит демон, WebUI, CLI и установщик. Go, компилятор и среда разработки на роутере не нужны. Интерфейс и основные рабочие сценарии BROray продолжаются; для перехода с 3.2 изменившаяся установка требует чистого окружения.

<a id="xray"></a>
## Xray и совместимость


При первой установке используется закреплённая версия **26.11.9**. Официальные версии выбираются на странице Xray. Архивы загружаются из XTLS/Xray-core с проверкой SHA-256; перед установкой пользователь видит совместимость с BROray. Для aarch64 на KN-1811 проверены HTTPS и UDP с 26.11.9; прежние результаты 26.10.31 и 26.10.21 сохранены. Это не означает аппаратную проверку всех протоколов на всех моделях. Для других архитектур смотрите конкретные сведения в реестре испытаний интерфейса.


<a id="protocols"></a>
## Протоколы и импорт в 3.5.4

| Формат | Как использовать |
| --- | --- |
| VLESS, VMess, Trojan, Shadowsocks | Ссылки сервера или поддержанный Xray JSON из подписки. Для Shadowsocks — без SIP003-плагинов. |
| Hysteria2 | hy2:// / hysteria2:// и Xray JSON с protocol: hysteria, version: 2. |
| SOCKS5, HTTP/HTTPS-прокси | socks:// / socks5:// / http:// / https:// или поддержанный Xray JSON. HTTP-прокси — только TCP. |
| WireGuard | Целиком клиентский INI или поддержанный Xray JSON из подписки; userspace Xray, без изменения сетевых интерфейсов ядра Linux. |
| AmneziaWG | vpn://: разбор и сохранение. Подключение, проверка качества и автовыбор не реализованы. |
| XDRIVE / MASQUE | Родной JSON: вставка, UTF-8 файл или подписка. Требуется Xray 26.11.9; реальные Google Drive/WARP не проверены. |
| TUIC / MTProto | Не поддерживаются. |

Наличие протокола в Xray не означает поддержку его импорта в BROray. JSON-профиль не переносится целиком: импортируются поддержанные параметры серверов. [Полная матрица и ограничения](https://github.com/BROadmin/BROray/blob/main/docs/PROTOCOL-SUPPORT.md).

<a id="paths"></a>
## Каталоги и команды


| Назначение | Путь |
| --- | --- |
| Команда BROray | `/opt/bin/broray` |
| Текущий исполняемый файл | `/opt/broray/current/broray` |
| Настройки приложения | `/opt/broray/config/config.v1.json` |
| Данные серверов, подписок, маршрутов | `/opt/broray/data/` |
| Xray | `/opt/broray/runtime/xray` |
| Запуск Entware | `/opt/etc/init.d/S24broray` |


Пути приведены для диагностики, а не для ручного удаления. Веб-файловый менеджер показывает накопитель: `storage:/tmp` и Linux RAM-каталог `/tmp` — не одно и то же. Готовые команды установки используют временный каталог RAM и удаляют только созданные ими загрузочные файлы.

<a id="policies"></a>
## Политики выпуска


- После обновления или перезапуска — повторный вход.
- Статические маршруты — без auto.
- На прошивках без UDP у ProxyN — TCP-only с предупреждением.
- Удаление через WebUI — только по локальному IPv4; работа через единственный внешний адрес имеет ограничения.
- Физически проверен KN-1811; полное удаление данных и часть сценариев с повреждением исправных настроек не заявлены как пройденные.


## Ограничения 3.5.4

- WireGuard на MIPS/MIPS LE не прошёл запуск в эмуляции официального Xray. Точная причина и поведение на настоящем MIPS-роутере неизвестны. Импорт и сохранение доступны, работоспособность этого протокола на MIPS не подтверждена.
- Google Drive/XDRIVE и настоящий WARP без выделенных реквизитов не проверялись. Local/S3/template и MASQUE H2/H3 проверены в изолированной VM с настоящим Xray и собственными тестовыми сервисами; это не проверка публичного провайдера.
- Аппаратная приёмка 3.5.4 выполнена на KN-1811/aarch64. Для ARMv7/MIPS/MIPS LE приведены результаты эмуляции, а не испытания на физических роутерах.
- Матрица охватывает 468 деклараций закреплённой клиентской схемы, включая явно неподдержанные поля и серверные исключения. Она не означает поддержку всех произвольных значений и сочетаний; криптографическую семантику и часть настроек проверяет само ядро перед запуском.
- AmneziaWG можно разобрать и сохранить, но подключение не реализовано. TUIC и MTProto не поддерживаются. XDRIVE требует согласованных версий Xray на клиенте и сервере; BROray не создаёт аккаунты WARP.
- WebUI проверен при отказе VPN и остановленном Xray, но внешний доступ по-прежнему зависит от WAN, DNS, KeenDNS и самого роутера. Прежний прямой WAN STUN не ответил; это не выдано за успешное сравнение прямого UDP с VPN.
