# Регламент постоянного FAQ BROray

Публичные адреса: /broray/faq/{slug}/. Номер выпуска не включается в заголовки, вопросы, ответы или адреса. Изменения выпусков ведутся отдельно в /broray/releases/.

Проверка каждого нового релиза и каждой повторной загрузки assets существующего релиза: сравнить опубликованные SHA-256 и время изменения; скачать и проверить контрольные суммы исходных ZIP; сравнить WebUI HTML/JS, backend и тесты; изменять только затронутые ответы с сохранением slug и id. Новые вопросы получают постоянный id. Наличие тестового файла не равно выполненному тесту.

После изменения сайта обновлять индекс поиска site.js, allowlist FILES в deploy.sh и SHA256SUMS. Сначала PR и проверка; без автоматического production-развёртывания.
