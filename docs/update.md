# Обновление до BROray 3.5.10

Обновление выполняется через WebUI. [Первая установка](installation.md) описана отдельно.

1. На странице **BROray** скачайте резервную копию настроек.
2. Нажмите **Проверить обновление**. Когда будет предложена **3.5.10**, нажмите **Установить обновление**.
3. Дождитесь завершения и войдите снова. Проверьте **3.5.10 r15** на странице **BROray**, а активный VPN и резервирование на странице **Серверы**.

Обновитель автоматически выбирает сборку и проверяет подписанный манифест Stable. Если у вас уже 3.5.10, выберите **Переустановить текущую версию**, когда WebUI предлагает подходящую ревизию. Для перехода с 3.2 [подготовьтесь к чистой установке](installation.md#from-32).
