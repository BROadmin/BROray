# Подготовка следующего выпуска: 3.1.1-r13

**Только локальная подготовка. Публикация приостановлена по указанию пользователя.**
Номер `3.1.1-r13c02` используется для локальной сборки; это не опубликованный
кандидат и не разрешение на его установку. WebUI проверяет пользователь;
браузерные тесты в этом этапе не запускаются.

## Черновик изменений

- Исправлен импорт Hysteria2 ссылок с `/` после порта, включая `hy2://` и IPv6.
  Такие узлы теперь принимаются из обычных и Base64 подписок.
- Автовыбор сервера проверяет HTTPS-трафик через действующее SOCKS-соединение
  Xray. Ответы на ping больше не определяют, работает ли VPN.
- Рабочий VPN с запрещённым ping не вызывает ложное переключение. Реальные
  ошибки передачи трафика учитываются в заданном пороге отказов.
- Если соединение восстановилось во время проверки резервных серверов,
  переключение отменяется. Сохраняется защита от частых переключений.
- Исправлена проверка локального SOCKS-адреса при обновлении: конфигурации с
  LAN-адресом, отличным от `192.168.1.1`, не отклоняются только из-за адреса.

## Состав локального комплекта

1. Воспроизводимая сборка приложения из зафиксированного коммита.
2. Отдельный архив исправленной updater platform, сверенный с копией внутри
   приложения. Все файлы и права проверяются, SHA-256 записываются в отчёт.
3. Этот черновик и перечень подтверждённых/оставшихся проверок.

Комплект не содержит публикуемого подписанного release index. Внешние каналы,
GitHub и сайт не меняются. Установленный на роутере r12 остаётся прежним.

## Доставка исправления updater

Исправленный updater нужен **до** захвата маршрутов. Одного обновления
приложения недостаточно: старый updater может отклонить нестандартный LAN
до переключения слота.

Для будущего выпуска нужно привязать новый архив platform и его SHA-256 к
подписанным метаданным штатного универсального установщика. Он выполняет
`ensure_target_platform()` до запроса обновления приложения. Подготовить также
новые точные зависимости clean-bootstrap. Нельзя использовать скрипт публикации
r12 без изменений: он копирует прежнюю platform. Старые публичные артефакты
должны остаться неизменными.

## Оставшиеся условия выпуска

- Результаты ручной проверки WebUI от пользователя.
- Приёмка подписанного комплекта и доставки platform перед захватом маршрутов.
- Физический update/rollback с новым updater, включая нестандартный LAN и
  сохранение управляемых и посторонних маршрутов.
- Реальное переключение между доступными VPN-узлами при отказе активного
  транспорта; изолированные тесты и read-only SOCKS-проба этого не заменяют.
- Повторная проверка совместимости Xray в объёме, затронутом изменениями.
- Отдельное разрешение пользователя снять текущую приостановку публикации.

Новая политика маршрутов при ручном выключении VPN остаётся предложением;
в эту сборку она не включена.
