# Пошаговая установка BROray для начинающих

Эта инструкция предназначена для пользователей, которые раньше не работали с Entware, SSH и командной строкой.

## Что потребуется

- совместимый роутер Keenetic с архитектурой `aarch64`;
- установленная система Entware `aarch64-3.10`;
- USB-накопитель или внутренний накопитель, подключённый в Keenetic как `/opt`;
- доступ к настройкам роутера;
- компьютер, смартфон или планшет, подключённый к этому роутеру;
- работающий интернет на роутере.

Если Entware уже установлен и работает, переходите сразу к разделу [2. Подключение к терминалу](#2-подключение-к-терминалу-при-необходимости).

## 1. Установка Entware — при необходимости

### Как понять, установлен ли Entware

Откройте веб-интерфейс Keenetic:

```text
http://192.168.1.1/
```

Перейдите в раздел **Приложения**. Если там есть запущенное приложение OPKG/Entware и выбран накопитель, повторная установка не требуется.

Также Entware уже установлен, если при подключении к терминалу выполняются команды:

```sh
opkg --version
ls -ld /opt
```

Если обе команды возвращают информацию без ошибки, переходите к разделу 2.

### Если Entware ещё не установлен

1. Подготовьте отдельный USB-накопитель. Лучше использовать надёжный SSD или HDD.
2. Перед форматированием сохраните нужные файлы: форматирование удалит все данные с выбранного накопителя.
3. Отформатируйте накопитель в `EXT4`.
4. Подключите накопитель к USB-порту Keenetic.
5. Откройте **Управление → Параметры системы → Изменить набор компонентов**.
6. Установите компоненты **Поддержка открытых пакетов** или **Пакеты OPKG**, поддержку файловой системы EXT и предложенные роутером модули файловых систем.
7. Дождитесь установки компонентов и перезагрузки Keenetic.
8. Установите Entware `aarch64-3.10` по инструкции для своей модели. Не используйте установщик для другой архитектуры.
9. Дождитесь сообщения об успешном завершении установки Entware.
10. Убедитесь, что накопитель подключён как `/opt`, а OPKG находится в состоянии **Работает**.

Актуальные установочные файлы и пояснения собраны в разделе [Entware на Keenetic Community](https://forum.keenetic.ru/topic/4299-entware/).

> [!IMPORTANT]
> Не продолжайте установку BROray, если OPKG не запущен или каталог `/opt` отсутствует.

## 2. Подключение к терминалу — при необходимости

Для установки BROray необходимо один раз открыть терминал Entware.

### Вариант A. Termius

Termius подходит для Windows, macOS, Linux, Android, iPhone и iPad. Загружайте приложение с [официального сайта Termius](https://termius.com/).

1. Установите и откройте Termius.
2. Создайте новое подключение **New Host**.
3. В поле адреса укажите LAN-адрес роутера, обычно `192.168.1.1`.
4. Укажите SSH-порт, настроенный для Entware.
5. В поле имени пользователя укажите `root`.
6. Введите пароль пользователя `root`, заданный при установке Entware.
7. Сохраните и откройте подключение.
8. При первом подключении убедитесь, что вы подключены к своему домашнему роутеру, и подтвердите его SSH-ключ.

### Вариант B. PuTTY для Windows

Загружайте PuTTY только с [официального сайта проекта](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html).

1. Установите и запустите PuTTY.
2. В поле **Host Name** укажите LAN-адрес роутера, обычно `192.168.1.1`.
3. В поле **Port** укажите SSH-порт Entware.
4. Выберите тип подключения **SSH** и нажмите **Open**.
5. Введите имя пользователя `root`.
6. Введите пароль Entware. При вводе пароль на экране не отображается — это нормально.

### Вариант C. Встроенный SSH-клиент

На Windows, macOS или Linux можно открыть терминал и выполнить:

```sh
ssh root@192.168.1.1
```

Если для Entware используется другой порт:

```sh
ssh -p НОМЕР_ПОРТА root@192.168.1.1
```

### Как понять, что открыт правильный терминал

Правильный Entware shell обычно показывает приглашение:

```text
~ #
```

или:

```text
root@router:~#
```

Если вы видите `(config)>`, это командная строка KeeneticOS, а не Entware. Команды установки BROray в ней выполнять нельзя. Подключитесь к SSH-порту Entware.

## 3. Чистая установка BROray

Чистая установка используется, если BROray ещё не установлен.

### Шаг 1. Установите необходимые инструменты

Скопируйте команду целиком, вставьте в терминал Entware и нажмите Enter:

```sh
opkg update &&
opkg install ca-bundle ca-certificates curl jq
```

Дождитесь окончания установки. Если команда завершилась ошибкой, не переходите к следующему шагу.

### Шаг 2. Запустите установку BROray

Скопируйте весь блок целиком, вставьте его в терминал и нажмите Enter:

```sh
(
set -eu
PATH=/opt/broray/bin:/opt/sbin:/opt/bin:/opt/usr/bin:/opt/usr/sbin:/usr/sbin:/usr/bin:/sbin:/bin
export PATH

for cmd in curl jq mktemp sha256sum awk sh rm; do
    command -v "$cmd" >/dev/null
done

T="$(mktemp /tmp/broray-clean-current.XXXXXX)"
trap 'rm -f "$T"' EXIT

curl -q \
  --proto '=https' \
  --proto-redir '=https' \
  --tlsv1.2 \
  --connect-timeout 15 \
  --max-time 600 \
  --retry 3 \
  -fsSL \
  -H 'Cache-Control: no-cache, no-store' \
  -H 'Accept-Encoding: identity' \
  'https://api.brovibe.cloud/releases/stable/broray/3.0.1-r07/INSTALL-ON-ROUTER.sh' \
  -o "$T"

[ "$(sha256sum "$T" | awk 'NR==1{print $1}')" = \
  '82d102e227fdaef2ea94708de8c540314e8c6b2cd89ab5a188cfcc771c37ff5d' ]

sh "$T"
)
```

Не закрывайте терминал и не перезагружайте роутер во время установки. Установка может временно останавливать и запускать Xray и интерфейс BROray.

### Шаг 3. Проверьте результат

Успешная установка заканчивается строками наподобие:

```text
BRORAY_INSTALL=PASS
CANDIDATE=3.0.1-r07c01
STABLE=YES
```

Если появилась строка `FAIL`, скопируйте текст ошибки, но не публикуйте пароль, ссылки подписок, UUID и приватные ключи.

### Шаг 4. Откройте WebUI

Откройте в браузере:

```text
http://192.168.1.1:8080/
```

Если адрес роутера отличается от `192.168.1.1`, используйте его фактический LAN-адрес.

Если на Keenetic настроен KeenDNS, также может быть доступен адрес:

```text
https://broray.<KeenDNS-домен-роутера>/
```

Порт `8080` в KeenDNS-адресе указывать не нужно.

### Шаг 5. Выполните первоначальную настройку

1. Войдите с учётной записью администратора Keenetic.
2. Откройте страницу **Подписки** или **Серверы**.
3. Добавьте подписку либо отдельный сервер.
4. Проверьте и подключите выбранный сервер.
5. Откройте страницу **Keenetic** и убедитесь, что управляемый ProxyN соответствует активному серверу.
6. При необходимости настройте DNS-over-TLS.
7. При необходимости установите готовые маршруты.

## 4. Обновление BROray

Обновление поддерживается с любой исправной версии BROray, начиная с `3.0.0-r1`.

При штатном обновлении сохраняются серверы, подписки, активное подключение, пользовательские и установленные маршруты, DNS-over-TLS, управляемый интерфейс Keenetic, установленный Xray и его рабочая конфигурация.

### Рекомендуемый способ через WebUI

1. Откройте WebUI BROray.
2. Перейдите на страницу **BROray**.
3. Нажмите **Проверить обновление**.
4. Если новая версия доступна, нажмите **Установить обновление**.
5. Подтвердите операцию и не нажимайте кнопку повторно.
6. Дождитесь сообщения об успешном завершении.
7. Очистите кэш браузера и обновите страницу: на компьютере нажмите `Ctrl+R`, на телефоне очистите кэш сайта и заново откройте страницу.
8. Проверьте страницы **Главная**, **Серверы**, **Keenetic**, **Xray** и **BROray**.

Если установленная версия старее, BROray обновится. Если версия уже актуальная, файлы приложения не изменятся. Более новая версия автоматически не понижается.

### Обновление через терминал

Если WebUI недоступен, используйте тот же проверяемый блок из раздела 3. При обычном обновлении уже установленного BROray повторно выполнять `opkg update` не нужно.

Для уже актуальной версии нормальным результатом будет:

```text
UPDATE_DECISION=already-current
INSTALLED_RELEASE=3.0.1-r07
CURRENT_RELEASE=3.0.1-r07
RELEASE_MUTATION=NONE
ENVIRONMENT_RECONCILED=YES
```

## 5. Переустановка текущей версии

Переустановка нужна, если файлы приложения повреждены, но пользовательские данные требуется сохранить.

1. Откройте страницу **BROray**.
2. Найдите раздел переустановки.
3. Нажмите **Переустановить текущую версию**.
4. Внимательно прочитайте план операции и подтвердите переустановку.
5. Дождитесь успешного завершения.
6. Очистите кэш браузера и снова откройте WebUI.

Не используйте вместо штатной переустановки `opkg upgrade broray`, `opkg --force-reinstall broray` или ручную замену файлов.

## 6. Удаление BROray

Удаляйте BROray только через WebUI.

1. Откройте страницу **BROray**.
2. Перейдите к разделу удаления.
3. Выберите нужный вариант удаления.
4. Прочитайте точный список данных, которые будут удалены или сохранены.
5. Если какие-либо данные нужны, отмените операцию и сначала сохраните их.
6. Подтвердите удаление и дождитесь сообщения об успешном завершении.

После полного удаления WebUI по адресу с портом `8080` перестанет открываться — это нормально. Удаление BROray и удаление самой системы Entware — разные операции. Не заменяйте штатное удаление ручным удалением каталогов `/opt/broray` или отдельных файлов.

Для повторной установки выполните раздел 3 заново.

## 7. Если что-то не получилось

### WebUI не открывается

- проверьте адрес `http://192.168.1.1:8080/`;
- убедитесь, что устройство подключено к домашнему Keenetic;
- временно отключите мобильный интернет на телефоне;
- очистите кэш сайта;
- попробуйте открыть страницу в другом браузере.

### Проверка служб через терминал

```sh
/opt/etc/init.d/S24broray status
/opt/etc/init.d/S25broray-web status
/opt/broray/bin/broray-system info
```

### Что отправить в поддержку

Можно отправить модель Keenetic, версию KeeneticOS, версию BROray, текст ошибки и результат проверки служб.

Не публикуйте пароль роутера, ссылку подписки, UUID сервера, приватный ключ, токен или полный файл конфигурации Xray.

Дополнительные сведения: [полная техническая инструкция](installation.md) и [требования к роутеру](requirements.md).
