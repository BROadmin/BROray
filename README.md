# BROray

**BROray — локальный клиент Xray и менеджер сетевых политик для совместимых маршрутизаторов Keenetic.** Приложение устанавливает и обслуживает Xray, принимает отдельные подключения и подписки, управляет штатным прокси-интерфейсом Keenetic, маршрутами и DNS-over-TLS через авторизованный WebUI.

> [!TIP]
> **Устанавливаете впервые?** Откройте [пошаговую инструкцию BROray для начинающих](docs/beginner-installation.md): Entware, Termius/PuTTY, чистая установка, обновление, переустановка и удаление без пропущенных шагов.

## Сильные стороны BROray

- **Единый WebUI.** Серверы, подписки, маршруты, DNS-over-TLS и обслуживание приложения в одном месте.
- **Выбор версии Xray.** Установка нужной версии ядра с указанием статуса совместимости с BROray.
- **Интеграция с Keenetic.** Управление интерфейсом ProxyN и адресом доступа к WebUI через KeenDNS.
- **Готовые наборы маршрутов.** Транзакционное применение наборов для популярных сервисов.
- **Контроль обновлений.** Подписанные релизы, проверки перед применением и механизм отката при ошибках.

BROray сокращает необходимость ручной работы в терминале, объединяя повседневную настройку и обслуживание в WebUI.

## Статус релиза

**BROray 3.2.0-r02 — Stable, 1 октября 2026 года.**

Выпуск использует проверенный `3.2.0-r02c01`. Предыдущий 3.2.0-r01 отозван из-за дефектов и остаётся отозванным. Относительно Stable 3.1.1 улучшены автоматика, импорт подписок, маршруты, WebUI и восстановление updater.

Полный функциональный цикл и двухчасовой прогон выполнены на c46. При переходе к r02 функциональный код сохранён; отдельно проверены обновление с r01, точные файлы, десять страниц WebUI и публичный комплект доставки. [Изменения, проверенные сценарии и ограничения](docs/RELEASE-3.2.0-r02.md).

## Требования к роутеру

- Keenetic с архитектурой `aarch64` и Entware `aarch64-3.10`;
- настроенный Open Package/Entware на одном накопителе, доступный как `/opt`;
- компоненты Keenetic `proxy`, `opkg` и `ndns`;
- root-доступ к Entware shell и исполняемый `/opt/bin/ash`;
- доступ к HTTPS и корректное время на роутере;
- не менее **64 МиБ** свободно на `/opt`;
- не менее **75 МиБ** свободно в `/tmp` и возможность создать 4096 временных файлов;
- рекомендуемый запас: от 100 МиБ на `/opt` и от 128 МиБ в `/tmp`.

Функциональный код проверен на KN-2710 / KeeneticOS 5.1.4; отдельные проверки r02 и ограничения описаны в [заметках к выпуску](docs/RELEASE-3.2.0-r02.md).

Прямое обновление с BROray 2.x не поддерживается: сохраните данные, удалите старую ветку и выполните чистую установку. Подробности: [требования и совместимость](docs/requirements.md).

## Короткая инструкция

### Обновление установленного BROray (3.0.0-r1 и новее)

Для перехода с прежних выпусков используйте проверяемый установщик ниже. Последующие обновления доступны через WebUI:

```text
BROray → Проверить обновление → Установить обновление
```

Поддерживается любая исправная установка, начиная с `3.0.0-r1`. Алгоритм один для всех выпусков: старая версия обновляется до текущего подписанного Stable, точный установленный кандидат завершается без переустановки, понижение запрещено. Если BROray ещё не установлен, этот же Stable-установщик выполняет чистую установку.

Для перехода со старой версии выполните в Entware shell от `root`:

```sh
(
set -eu
PATH=/opt/broray/bin:/opt/sbin:/opt/bin:/opt/usr/bin:/opt/usr/sbin:/usr/sbin:/usr/bin:/sbin:/bin
export PATH
for cmd in curl jq mktemp sha256sum awk sh rm; do command -v "$cmd" >/dev/null; done
T="$(mktemp /tmp/broray-stable-update.XXXXXX)"
trap 'rm -f "$T"' EXIT
curl -q --proto '=https' --proto-redir '=https' --tlsv1.2 \
  --connect-timeout 15 --max-time 600 --retry 3 -fsSL \
  -H 'Cache-Control: no-cache, no-store' -H 'Accept-Encoding: identity' \
  'https://api.brovibe.cloud/releases/stable/broray/3.2.0-r02/INSTALL-ON-ROUTER.sh' \
  -o "$T"
[ "$(sha256sum "$T" | awk 'NR==1{print $1}')" = \
  'd635f05ec0426bcb11f5cb666874301d06dba5d53b4ed33ef27d14e11a80d2a1' ]
sh "$T"
)
```

### Установка с нуля

Если BROray на роутере ещё не установлен:

1. Откройте терминал Entware на роутере.
2. Войдите как `root`.
3. Один раз выполните команду установки необходимых пакетов:

```sh
opkg update &&
opkg install ca-bundle ca-certificates curl jq
```

Если BROray уже установлен и вы его обновляете, пропустите этот шаг.

Затем запустите текущий подписанный Stable-установщик:

```sh
(
set -eu
PATH=/opt/broray/bin:/opt/sbin:/opt/bin:/opt/usr/bin:/opt/usr/sbin:/usr/sbin:/usr/bin:/sbin:/bin
export PATH
for cmd in curl jq mktemp sha256sum awk sh rm; do command -v "$cmd" >/dev/null; done
T="$(mktemp /tmp/broray-clean-current.XXXXXX)"
trap 'rm -f "$T"' EXIT
curl -q --proto '=https' --proto-redir '=https' --tlsv1.2 \
  --connect-timeout 15 --max-time 600 --retry 3 -fsSL \
  -H 'Cache-Control: no-cache, no-store' -H 'Accept-Encoding: identity' \
  'https://api.brovibe.cloud/releases/stable/broray/3.2.0-r02/INSTALL-ON-ROUTER.sh' \
  -o "$T"
[ "$(sha256sum "$T" | awk 'NR==1{print $1}')" = \
  'd635f05ec0426bcb11f5cb666874301d06dba5d53b4ed33ef27d14e11a80d2a1' ]
sh "$T"
)
```

На чистом окружении установщик сам проверяет отсутствие частичной установки и сразу разворачивает целевое приложение `3.2.0-r02c01`. Пакет OPKG `3.0.0-r14` служит только регистрационным якорем: промежуточное приложение `r14c68` не устанавливается и не запускается, готовность updater подтверждается через защищённый preflight; может потребоваться перезагрузка. После успешной установки WebUI доступен по адресу `http://<LAN-IP-роутера>:8080/`.

> После обновления обязательно очистите кэш браузера и заново откройте WebUI. На компьютере обновите страницу сочетанием `Ctrl+R`; на мобильном устройстве очистите кэш сайта в настройках браузера и перезагрузите страницу.

Если на роутере настроен KeenDNS, BROray также создаёт отдельный адрес без порта `8080`:

```text
http://broray.<KeenDNS-домен-роутера>/
```

HTTP автоматически перенаправляется на защищённый адрес `https://broray.<KeenDNS-домен-роутера>/`. Например, для домена роутера `myrouter.keenetic.link` откройте `https://broray.myrouter.keenetic.link/`. Доступность этого адреса из локальной или внешней сети определяется режимом KeenDNS и настройками самого роутера.

### Альтернативная установка через штатный механизм Keenetic

Для устройств, где удобнее использовать каталог автозапуска Entware, сохранён отдельный альтернативный bootstrap базовой установки `3.0.0-r14c68` через штатный механизм `/opt/install/*.tgz`. Этот исторический вариант требует последующего запуска актуального проверяемого установщика для обновления до текущего Stable `3.2.0-r02`; обычная терминальная установка выше сразу разворачивает текущий Stable.

- архив: [`broray-webcli-bootstrap-3.0.0-r14c68-b1.tgz`](https://api.brovibe.cloud/releases/bootstrap/broray/3.0.0-r14c68-b1/broray-webcli-bootstrap-3.0.0-r14c68-b1.tgz);
- SHA-256: `50904456e998dc501ee534efca5eccc47b997f9986bf5aef3f959d468ad66dd7`;
- key ID: `aaac0ea3b4a6334c`;
- результат физической проверки: **PASS**.

Web CLI Keenetic не является Linux shell и не загружает файл. Сначала проверьте внешнюю подпись на компьютере, затем скопируйте архив в `/opt/install/` через SFTP или USB и выполните штатную перезагрузку. [Полная инструкция и файлы проверки](docs/keenetic-web-cli-install.md).

### Что сохраняется при обновлении

Обновитель проверяет подпись Stable index, SHA-256 и итоговое состояние служб. Серверы, подписки, пользовательские маршруты, DNS-over-TLS, управляемый интерфейс и установленный Xray находятся вне сменяемого app-slot и сохраняются.

### Аварийное административное обновление

Если WebUI недоступен, повторите в root-shell команду из раздела «Обновление любой установленной версии 3.0.0». Универсальный Stable-установщик определит состояние автоматически:

- установлена более старая исправная версия 3.0.0 — выполнит обновление;
- уже установлен текущий Stable — завершится без изменений;
- установлена более новая версия — откажется от понижения без изменений.

Это не «принудительная установка»: несовместимое, повреждённое или неоднозначное состояние будет отклонено без обхода защитных проверок. Не используйте `opkg upgrade`, `opkg --force-reinstall` или ручную замену `/opt/broray/current`.

Полная инструкция: [установка и обслуживание](docs/installation.md).

## Основные возможности и страницы WebUI

| Страница | Назначение |
| --- | --- |
| **Главная** | Быстрый сводный статус серверов, подписок, маршрутов, Keenetic, Xray и BROray. Читает подготовленные фоновые снимки, поэтому открывается быстро и не запускает тяжёлые проверки сама. |
| **Серверы** | Импорт VLESS, VMess, Trojan и Hysteria2, ручная и автоматическая проверка качества, подключение, отключение, просмотр и удаление серверов, автоматический выбор резервного сервера. |
| **Подписки** | Добавление, обновление и удаление подписок, просмотр полученных серверов и безопасное обновление списка без потери активного подключения. |
| **DNS-over-TLS** | Выбор до восьми DoT-серверов, TLS/SNI-проверка, применение в Keenetic и удаление только тех записей, которыми действительно управляет BROray. |
| **Маршруты — Обзор** | Сводка готовых и пользовательских наборов, состояние установки, обновления и конфликты владельцев маршрутов. |
| **Маршруты — Свои маршруты** | Импорт BAT как данных, предварительная проверка, нормализация, удаление дублей, установка, обновление и удаление пользовательских наборов. BAT-файлы не выполняются как команды. |
| **Маршруты — Готовые маршруты** | Десять готовых наборов: Telegram, WhatsApp, YouTube, ChatGPT/OpenAI, Instagram, Facebook, Meta, TikTok, Speedtest и Wikipedia. Поддерживаются проверка источника, планирование и транзакционное применение. |
| **Keenetic** | Диагностика управляемого прокси-интерфейса, создание или восстановление после ручного удаления, синхронизация имени `BROray - <активный сервер>`, проверка связи с Xray и управление адресом WebUI через KeenDNS. |
| **Xray** | Версия, состояние процесса и конфигурации, запуск, остановка, перезапуск, диагностика, проверка обновления, обновление и безопасная переустановка с динамической проверкой места. |
| **BROray** | Версия приложения и компонентов, канал обновлений, проверка обновления, переустановка, восстановление, журнал операции и авторизованное удаление. |

Вход в WebUI защищён локальной сессией. Служебные страницы входа и совместимости не выполняют сетевые изменения. Подробный справочник: [WebUI](docs/webui.md).

## Что нового в версии 3.2.0

- **Приоритеты фоновых операций.** Проверка активного соединения получает преимущество; длительные задания выполняются короткими этапами. Исправлены пауза и возобновление автоматики, обновление результатов проверок и статус активного подключения.
- **Подписки без потери узлов.** Исправлены BOM и пробелы, дедупликация по параметрам подключения и сохранение ID при однозначной смене реквизитов. Исчезнувшие серверы удаляются после полного успешного обновления; при частичном ответе сохраняются с предупреждением.
- **Больше поддерживаемых конфигураций.** Расширены VLESS, VMess, Trojan, Hysteria2 и JSON-импорт Shadowsocks. Добавлены современные VMess URI, Vision-udp443, mKCP, поддерживаемые TLS/REALITY, XHTTP и FinalMask-параметры. Существующие варианты SIP002/AEAD-2022 сохранены.
- **Надёжнее обновление и запуск.** Исправлены повторный запуск updater, восстановление после перезагрузки, блокировки старой миграции и запуск служб/WebUI. Ожидания завершения служб согласованы с их фактическим состоянием.
- **Установка и удаление.** LAN-адрес определяется по конфигурации Keenetic с выбором при неоднозначности. Полное удаление может продолжить незавершённые шаги; Entware и чужие настройки сохраняются. Маршруты удаляет Keenetic при удалении принадлежащего BROray интерфейса.
- **Маршруты и DNS-over-TLS.** Исправлены установка готовых маршрутов, обновление их статусов, создание интерфейса после удаления и автопроверка DoT. Устаревшее подтверждение удаления DoT отклоняется без изменений.
- **Совместимость Xray.** Результаты сохраняются между кандидатами при неизменных проверенных компонентах. Частично совместимую версию можно установить после подтверждения ограничений. Добавлены данные для 26.9.30.
- **Подготовка Xray в RAM.** Загрузка и проверка выполняются в оперативной памяти; доступное место проверяется до остановки рабочего ядра.
- **WebUI.** На Главной появилась отдельная карточка DoT; исправлены версия приложения, статусы, мобильная вёрстка и сообщения об ошибках. Журнал и история фоновых операций раскрываются по запросу.
- **Обслуживание хранилища.** Исключена неиспользуемая графика; обычные логи ротируются, завершённая история обслуживается по безопасным правилам. Защищённые сведения восстановления не удаляются ради квоты.

[Подробности и ограничения](docs/RELEASE-3.2.0-r02.md).

## Исходный код релиза

Исходники 3.2.0 находятся в [`runtime/`](runtime/), дополнительные исходники — в `native/`, `compat/` и `bootstrap/`, проверки — в `tests/`.
Исторический каталог `root/` не используется для сборки 3.2.0.
Точное происхождение опубликованных файлов и контрольные суммы указаны в `STABLE-PROMOTION-PROOF.json` и `SHA256SUMS` в составе релиза.
